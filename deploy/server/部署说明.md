# Windows 服务器包的配置入口

将服务器包完整解压到 `C:\Exam\Server`。以下路径以此为例，换用其他目录时一并修改配置中的绝对路径。每个受管节点都需要部署业务服务和独立管理服务。

| 内容 | 包内位置 | 部署后的用途 |
| --- | --- | --- |
| 业务程序 | `Exam.Server\Exam.Server.exe` | 考试、登录、试题和答卷 API |
| 管理程序 | `Exam.Management\Exam.Management.exe` | 独立管理 API，业务停机时仍可运行 |
| 业务配置模板 | `samples\service-management\appsettings.business.example.json` | 填写后放到 `Exam.Server\appsettings.json` |
| 管理配置模板 | `samples\service-management\appsettings.management.example.json` | 填写后放到 `Exam.Management\appsettings.json` |
| 服务配置模板 | `samples\service-management\service-configuration.example.json` | 填写后放到 `C:\Exam\configuration\service.json` |
| 主备配置模板 | `samples\service-management\appsettings.high-availability.example.json` | 合并到对应宿主配置中 |
| 安装入口 | `deploy\server\Install-WindowsServices.ps1` | 注册两个 Windows 服务 |
| 考务连接导出 | `deploy\management\Export-AdminConnection.ps1` | 为考务电脑生成连接文件 |

## 配置顺序

1. 按 [PostgreSQL 部署说明](deploy/postgresql/README.md)准备首台节点的 PostgreSQL 18、存储和服务账户。完成数据库迁移后，仅新空库的选定首台主机可显式配置 HighAvailability:BootstrapPrimary=true 初始化权威身份。已有考试库不能重新初始化。需要双机保护时，第二台从当前活动主机建立副本，不得单独创建另一个主集群。
2. 根据三个基础模板填写实际身份和路径。两台服务器使用同一个 `ServerId`，各有自己的 `NodeId`。将模板中的 `C:\ExamSynthetic` 替换为实际目录，配置中的服务名称、数据库连接和证书也都要替换。
3. 按[服务器详细说明](deploy/server/README.md)补齐数据库、本机确认目录、已部署节点的题包公钥、容量和学生受信连接配置。单台节点只列自身；双机增加备节点公钥和受信连接。示例配置不会自动合并，需要把相应节写入各宿主的 `appsettings.json`。
4. 将共享服务配置保存到 `C:\Exam\configuration\service.json`，并让两个宿主的 `Management:ServiceConfigurationPath` 都指向它。建议数据位于 `C:\Exam\data`，证书位于 `C:\Exam\certificates`，备份位于 `C:\Exam\backups`。为服务账户配置这些目录及私钥的访问权限。
5. 配置业务 HTTPS 443 和管理 HTTPS 9443 的监听、证书与防火墙。证书覆盖客户端访问的域名或 IP。主备保护和初始备份的要求见[恢复运行手册](docs/backup-and-failover-runbook.md)。

## 注册和启动服务

在服务器上使用管理员 PowerShell 7，将凭据替换为实际服务账户。

```powershell
$serviceAccount = Get-Credential
& C:\Exam\Server\deploy\server\Install-WindowsServices.ps1 `
  -DeploymentDirectory C:\Exam\Server -ServiceCredential $serviceAccount
```

安装脚本只注册服务。配置完成后，按 `Exam.Management\appsettings.json` 中的 `Management:ServiceName` 启动管理服务，再通过管理 API 或考务 CLI 启动业务服务。业务服务默认设为手动启动；管理服务设为自动启动。

## 向考务电脑交付管理连接

先创建用于交付连接文件的目录，再填写服务器实际域名或 IP。下面的 IP 仅演示参数格式。

```powershell
New-Item -ItemType Directory -Path C:\Exam\AdminConnection -Force
pwsh -File C:\Exam\Server\deploy\management\Export-AdminConnection.ps1 `
  -ManagementConfigurationPath C:\Exam\Server\Exam.Management\appsettings.json `
  -AdminDirectory C:\Exam\AdminConnection -HostName 192.168.1.20
```

双节点部署须额外提供 `-PeerManagementConfigurationPath` 和 `-PeerHostName`，将包含双方连接的 `C:\Exam\AdminConnection\management-connection.json` 放到两端考务程序旁。考务端和学生端的登录页填写业务地址，默认连接 HTTPS 443。

## 故障接管

备机失联时，健康主机自动按本机可靠落盘继续服务，管理页清楚显示单节点运行。主机故障时，先实际断电或隔离旧主全部业务网络，再从考务登录页“主服务器故障，直接进入服务器管理”进入备机，使用原账号登录并点击“接管为主服务器”。接管完成会启动业务并等待就绪，无需额外启用应急模式。

界面上的隔离确认不执行硬件断电或网络隔离；没有真实隔离不能接管。发生接管的旧主保持隔离，使用“重建旧节点”从当前主机重建为备机后再加入。普通备机恢复会自动追平数据、资源和独立持久确认。具体步骤见 docs/high-availability-management.md。
