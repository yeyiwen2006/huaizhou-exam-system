# 考务端部署

将考务发布包完整解压到 Windows 电脑，例如 `C:\Exam\Admin`，双击 `启动考务端.cmd` 或 `Exam.Admin.exe`。程序包自带 .NET 运行时。

登录页填写考试业务服务器的局域网 IP 或域名，默认使用 HTTPS 443。其他端口填写完整 HTTPS 地址。首次使用可以注册考务账号，服务器的首个账号自动成为管理员，后续账号由管理员批准。

使用 Radmin VPN 时，考务端对 `26.*` IPv4 地址直接连接，避免系统网页代理转发虚拟局域网请求；访问公网 HTTPS 域名仍沿用系统代理设置。两种连接均保留原有 HTTPS 证书校验。

## 配置服务器管理

部署人员在服务器上运行 `Export-AdminConnection.ps1`，将生成的 `management-connection.json` 放到考务电脑 `Exam.Admin.exe` 旁。服务器管理页面统一显示主机、备机与自动备份状态，使用右上角“刷新”，不再提供手工切换管理服务器或导入配置界面。

双节点部署必须为导出脚本提供 `-PeerManagementConfigurationPath` 和 `-PeerHostName`。检测到双节点配置却未提供对端参数时，脚本会提示补齐，不再导出缺少备机的连接文件。两份受保护管理配置必须属于同一逻辑服务器、不同节点；导出的文件只包含 `address/serverId/nodeId/peerAddress/peerNodeId`，不含口令或令牌。界面按选中的节点使用各自的管理连接和独立会话，不猜测对端端口，也不把一个节点的管理令牌转交另一个节点。

原先保存的单节点连接若与部署文件中的某个节点地址和身份完全相同，会自动补齐另一节点。若实际地址或逻辑身份已变更，由部署人员更新用户管理连接文件；不通过忽略证书或保留错误身份来强行连接。单节点部署仍兼容原来的三字段文件。

管理连接文件中填写的是独立管理服务地址，通常使用 9443 端口。它与登录页的业务地址用途不同。使用内部 CA 签发的 HTTPS 证书时，在考务电脑安装对应信任链，并使用证书覆盖的域名或 IP。

## 试题编译和运维

编译或重新编译 TeX 试题时，需要安装 TeX Live 或 MiKTeX，并让 `xelatex` 可从 `PATH` 找到。题目使用的字体、宏包及图片也要齐全。名单和成绩 Excel 文件由程序读取，无需安装 Microsoft Excel。

`cli\Exam.Cli.exe` 为命令行考务工具。详细参数见同目录的 `使用说明.md`。服务器的程序、证书私钥和数据库配置由部署人员保留在服务器上。
