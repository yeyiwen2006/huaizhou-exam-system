# D03 选项定位契约（草案，待 A 确认）

状态：**待 A 确认**。本记录提出选项定位区域的抽取路线与规则，用于解除 D03 与 B03 之间的坐标依赖。
关联 [#26](https://github.com/yeyiwen2006/huaizhou-exam-system/issues/26)。

## 一、问题

[执行指南](../agent-implementation-guide.md)第 170 行规定：用 hyperref 隐藏外观链接标记选项，目标只含题目和选项标识，
**PdfPig 提取区域**后按坐标规范转换；第 242 行把「隐藏选项标记、PDF 区域提取与归一化」列为 D03 的开发内容，
并要求「D 与 B 共同明确坐标契约并由 A 确认，不等待 B03 完整实现」。

实现抽取时发现：**现标记形式不产生任何注解对象，PdfPig 没有任何区域可读**。合成样包样式定义的是零尺寸命名目标：

```latex
\DeclareRobustCommand{\optmark}[2]{\hypertarget{opt:#1:#2}{}}
```

`\hypertarget` 只写入 PDF 的命名目标树，不生成注解。按现形式直接实现，抽取结果为空。

需要区分两件事：**需要变的是标记宏的行为（如何被读出来），不是它的接口，也不是 D01 的分工或交付**。
因此本记录要 A 决定的不是「改不改 D01」，而是「**在几条抽取路线里选哪一条**」。

## 二、本机实测证据

用 XeLaTeX（MiKTeX 26.5 / XeTeX 4.18）编译合成探针 PDF，再用 PdfPig 0.1.16 读取。
**探针内容全部为本次临时编写的合成文本，未使用任何真实试卷材料；产物写在系统临时目录，材料目录未产生文件。**

| 探针形式 | 结果 |
| --- | --- |
| `\hypertarget{opt:q:A}{}` 零尺寸目标 | 该页 **0 条注解**；PdfPig 公开 API 无命名目标接口（反射检索 `PdfDocument` 的 Destination/Name 成员为空） |
| `\hyperlink{opt:q:A}{A.}` + `hidelinks`，链接仅包选项字母 | 每个选项 **1 条 `Link` 注解**，`/Border [0 0 0]`（隐藏外观），`/A << /S /GoTo /D (opt:q:A) >>`，`/Rect` 紧贴字母（宽 12.03、高 16.82；同行文字起点 x=137.38，矩形 x 起点 137.01） |
| `\hyperlink{...}{选项正文}`，链接包选项正文 | 矩形覆盖正文但不含字母标签（字母在 `\item[...]` 标签内，无法与正文同框） |
| 同上，且选项正文换行（3 行） | 同一目标名产出 **3 条注解**，每行一条，`/Rect` 互不相同 |
| 目标名未定义（悬空链接） | 注解仍在但形态变化（3 行合成 1 条），`Action` 解析为 null |
| 页面带 `/Rotate 90` 与小于 MediaBox 的 `/CropBox` | `page.Width/Height` 为**旋转后的显示尺寸**（800×550）；注解矩形出现 `Left(723.91) > Right(707.09)` 的**退化角序**，不能假设 `Left < Right`、`Top > Bottom` |

推论：

1. 零尺寸目标路线下 PdfPig 无区域可读，必须改走能产生可读几何的路线（见第三节）。
2. 区域按**目标名**归属，不按注解条数：一个选项可能对应多条注解，抽取必须按目标名分组取并集。
3. 链接必须同时定义目标（`\hypertarget`）与引用（`\hyperlink`），悬空链接的注解形态不稳定。
4. 旋转与裁剪必须显式处理，且矩形角序要规范化。
5. PdfPig 对 CJK 字形的度量不可靠（无 CJK 字体时字形读作未映射码位、宽度失真）。**几何一律以注解 `/Rect` 为准，不得从字形包围盒反推**。

### 在合成样包上的验证

按第四节的形式更新合成样包后，用 XeLaTeX 实际编译两个样包，再按本草案规则（按目标名分组、校验命名、归一化）用 PdfPig 抽取。
产物写在系统临时目录，两个样包目录均未产生任何文件：

| 样包 | 结果 |
| --- | --- |
| `ordering`（`排序合成考试_1`） | 4 个唯一目标 `opt:q-d-001:A..D`，各 1 条注解，均在第 1 页；归一化后 x 同为 0.2335 附近，y 依次 0.1885 / 0.2192 / 0.2500 / 0.2807，全部落在 `[0,1]` |
| `figures-chemistry`（`图形化学合成考试_51`） | 4 个唯一目标 `opt:q-c-051:A..D`，**均在第 2 页**（插图把选项推到次页），数值同量级且单调 |

同一题的选项 x 一致、y 单调等距，说明归一化方向与基准正确；含图样包跨页归属正确，说明页索引可用。
覆盖两个样包共 8 个选项，**未覆盖旋转、裁剪、多行与表格选项**。

## 三、抽取路线与取舍

三条路线，代价差异很大。**只有路线 A 经过实测；B、C 未实测，代价为分析估计。**

| | 路线 A：隐藏外观链接 | 路线 B：编译期记位置 | 路线 C：D03 解析命名目标树 |
| --- | --- | --- | --- |
| 标记宏接口 | **需改**：加显示文本参数 | **不改**，仅改宏体 | **不改** |
| 样包 64 处调用点 | 需改 | 不改 | 不改 |
| D03 拿到 | 真实**矩形** | **锚点**（点） | **锚点**（点） |
| 读取方式 | PdfPig 读注解 `/Rect`（指南指定） | 读编译期写出的位置文件 | 手写 PDF 命名目标树解析 |
| 依赖 | 新增 PdfPig（指南已指定） | 样式需 `zref-savepos` 一类方案 | 需自研 PDF 解析 |
| 编译流程 | 不变 | **需多跑一遍**才有位置 | 不变 |
| 与执行指南 | **一致**（第 170 行原文） | 偏离 | 偏离（且 PdfPig 无此 API） |
| 实测状态 | **已实测通过** | 未实测 | 未实测 |

补充一条影响判断的交互事实：合成样包样式自己的注释写的是「B03 据此在选项字母处叠加**圆形**控件，圆钮第 i 个对应 `options[i]`」。
圆钮只需要一个**圆心**，不需要矩形。也就是说路线 B/C 给的锚点在交互上可能已经够用，路线 A 的矩形是顺带得到的能力。

**D 侧倾向路线 A**，理由：它是执行指南第 170 行原文指定的路线（「用 hyperref 隐藏外观链接标记选项，PdfPig 提取区域」），
是唯一不偏离指南的方案，且已实测通过、直接给出矩形。代价是必须改标记宏接口与全部材料样式。
若 A 认为「不动接口」的权重更高，B 可行，但需要先实测确认 XeTeX 下位置记录与裁剪旋转的关系，D 可以补做。

## 四、路线 A 的契约草案

以下按 D 倾向的路线 A 展开；若 A 选 B 或 C，本节需相应改写。

### 4.1 标记定义（材料样式提供）

```latex
% \optmark{题目标识}{选项标识}{选项显示文本}
% 在选项显示文本外建立隐藏外观链接，目标名固定为 opt:<题目标识>:<选项标识>。
% 不改变外观与占位；目标名只含题目与选项标识，不含答案、分值等任何计分信息。
\DeclareRobustCommand{\optmark}[3]{\hypertarget{opt:#1:#2}{}\hyperlink{opt:#1:#2}{#3}}
```

与原形式只有一处实质变化：**显示文本作为第 3 参数进入链接**，使链接矩形落在选项字母上。
显示文本无法由选项标识推出（同一份材料中并存 `A.` 与 `（A）` 两种写法），故必须显式传入。

### 4.2 抽取规则

- 每个清单已声明选项必须**恰好对应一个区域**（同名多注解按并集合并为一个）。
- 选项缺失区域、出现清单未声明的标记、同一目标名跨题冲突：**一律失败**，不产出部分产物、不静默跳过。
- 目标名解析不出目标（悬空链接）：失败。
- 目标名格式不匹配 `opt:<questionId>:<optionId>`：失败。
- 区域数量与清单选项数不一致时不得发布。

### 4.3 归一化定义（`anchorScheme = pageTopLeftNormalizedV1`）

- 基准为**该页旋转后的显示尺寸**，矩形相对**该页 CropBox** 度量；即先按 `/CropBox` 裁剪、再按 `/Rotate` 旋转到显示方向。
- 原点在显示页面**左上角**，x 向右、y 向下，两者均除以对应的显示尺寸归一化到 `[0,1]`。
- 实现必须先把 `/Rect` 的四个角规范化（取 min/max），再变换，不能假设角序。
- 超出 `[0,1]` 的区域视为异常并失败。
- 必测矩阵：旋转 `0/90/180/270` × 裁剪「无 / 小于 MediaBox 且带偏移」。
- 页索引基准（1 起或 0 起）需与 B03 对齐后写死，不得一侧默认。

### 4.4 产物形态

选项定位区域**不写入清单**（与 [逐题显示元数据 schema](../schemas/display-metadata.schema.json) 一致），
随 `paperVersion` 作为独立版本产物发布，由 B03 按试卷版本读取。建议形态：

```json
{
  "artifactVersion": 1,
  "anchorScheme": "pageTopLeftNormalizedV1",
  "paperVersion": 3,
  "questions": [
    {
      "questionId": "q-001",
      "options": [
        { "optionId": "A", "pageIndex": 1, "x": 0.2239, "y": 0.1900, "width": 0.0197, "height": 0.0212 }
      ]
    }
  ]
}
```

新旧版本各自独立发布与恢复，不得覆盖既有版本产物。

### 4.5 依赖

抽取需要 PDF 读取能力。执行指南已指定 **PdfPig**，本机验证其 0.1.16 可读取全部所需字段
（注解类型、`/Rect`、原始字典中的目标名）。该依赖为新增，需 A 与 E 确认对锁定还原与 CI 的影响。
