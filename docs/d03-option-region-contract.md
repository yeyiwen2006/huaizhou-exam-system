## 一、问题

[执行指南](../agent-implementation-guide.md)第 170 行规定：用 hyperref 隐藏外观链接标记选项，目标只含题目和选项标识，

并要求「D 与 B 共同明确坐标契约并由 A 确认，不等待 B03 完整实现」。

实现抽取时发现：**现标记形式不产生任何注解对象，PdfPig 没有任何区域可读**。合成样包样式定义的是零尺寸命名目标：

```latex
\DeclareRobustCommand{\optmark}[2]{\hypertarget{opt:#1:#2}{}}
```

`\hypertarget` 只写入 PDF 的命名目标树，不生成注解。按现形式直接实现，抽取结果为空。

本次决定调整标记宏的行为，并将接口从两参数改为三参数。D01 的既有交付和任务分工保留，
后续标记抽取仍由 D03 实现，真实材料的样式适配在 D06 跟踪。

## 二、D 提交提案时的实测记录

以下为 D 在原提案中记录的实验，A 本次没有重跑这些实验。D 用 XeLaTeX（MiKTeX 26.5 / XeTeX 4.18）
编译合成探针 PDF，再用 PdfPig 0.1.16 读取。探针全部为合成文本，未使用真实试卷材料；
产物写在系统临时目录，材料目录未产生文件。

| 探针形式 | 结果 |
| --- | --- |
| `\hypertarget{opt:q:A}{}` 零尺寸目标 | 该页 **0 条注解**；PdfPig 公开 API 无命名目标接口（反射检索 `PdfDocument` 的 Destination/Name 成员为空） |
| `\hyperlink{opt:q:A}{A.}` + `hidelinks`，链接仅包选项字母 | 每个选项 **1 条 `Link` 注解**，`/Border [0 0 0]`（隐藏外观），`/A << /S /GoTo /D (opt:q:A) >>`，`/Rect` 紧贴字母（宽 12.03、高 16.82；同行文字起点 x=137.38，矩形 x 起点 137.01） |
| `\hyperlink{...}{选项正文}`，链接包选项正文 | 矩形覆盖正文但不含字母标签（字母在 `\item[...]` 标签内，无法与正文同框） |
| 同上，且选项正文换行（3 行） | 同一目标名产出 **3 条注解**，每行一条，`/Rect` 互不相同 |
| 目标名未定义（悬空链接） | 注解仍在但形态变化（3 行合成 1 条），`Action` 解析为 null |
| 页面带 `/Rotate 90` 与小于 MediaBox 的 `/CropBox` | `page.Width/Height` 为**旋转后的显示尺寸**（800×550）；注解矩形出现 `Left(723.91) > Right(707.09)` 的**退化角序**，不能假设 `Left < Right`、`Top > Bottom` |

推论：

1. 零尺寸目标路线下 PdfPig 无区域可读，必须改走能产生可读几何的路线（见第三节）。
2. 区域按**目标名与所在页**归属。同名注解不能无条件取并集，路线 A 的标签范围及重复标记规则见 4.1、4.2。
3. 链接必须同时定义目标（`\hypertarget`）与引用（`\hyperlink`），悬空链接的注解形态不稳定。
4. 旋转与裁剪必须显式处理，且矩形角序要规范化。
5. PdfPig 对 CJK 字形的度量不可靠（无 CJK 字体时字形读作未映射码位、宽度失真）。**几何一律以注解 `/Rect` 为准，不得从字形包围盒反推**。

## 四、路线 A 的实现契约

本节固定数据语义和接入边界，后续实现 PR 同步交付代码、schema、合成样包及模块验证。

### 4.1 标记定义（材料样式提供）

```latex
% \optmark{题目标识}{选项标识}{选项标签文本}
% 第三参数只包选项字母及原有标点，如 A. 或 （A），不得包正文、表格或图片。
% 在标签外建立隐藏外观链接，目标名固定为 opt:<题目标识>:<选项标识>。
% 不改变外观与占位；目标名只含题目与选项标识，不含答案、分值等任何计分信息。
\DeclareRobustCommand{\optmark}[3]{\hypertarget{opt:#1:#2}{}\hyperlink{opt:#1:#2}{#3}}
```

标签文本作为第 3 参数进入链接，使链接矩形落在选项字母上。标签无法由选项标识推出，
同一份材料中可以并存 `A.` 与 `（A）`，因此显式传入。样式加载 hyperref 后设置 `\hypersetup{hidelinks}`。
每个选项只调用一次宏，标签保持单行。正文可多行、含图或表格，不改变标签矩形的范围。
`hidelinks` 隐藏链接外观，仍保留 Link 注解；不得设置使注解本身不可用的隐藏标志。

### 4.2 抽取规则

- 使用 `page.GetAnnotations()` 筛选 Link 注解，从原始动作字典的 `/A /D` 或直接目标 `/Dest` 读取目标名。
  `Annotation.Name` 对应 `/NM`，不能充当目标名；不得依赖只提取外部链接的 `GetHyperlinks()`。
- 标记必须解析为同一 PDF 内的 GoTo 目标，且目标页与注解页一致；远程目标、其他动作或无法解析的目标失败。
- 只处理 `opt:` 命名空间。普通链接不计入选项数；`opt:` 标记格式错误、悬空或指向其他题目时失败。
- 按清单生成完整的预期目标名，以大小写敏感的精确比较绑定 `(questionId, optionId)`。
  现有 schema 不限制标识内的冒号，不能直接按冒号拆成固定三段；若两组标识产生相同目标名，报告冲突并拒绝发布。
- 每个清单选项必须恰好对应一个标签区域。通常每项只有一条注解；确有碎片时，仅允许同页且相互重叠或相接、
  连通的碎片取矩形并集。同名但分离的标签按重复标记失败，同名跨页也失败，禁止跨页取并集。
- 选项缺失区域、清单外标记、重复或无效区域均使整次抽取失败，不产出部分文件。错误包含题目标识、选项标识和所在页。
- 最终结果按清单选项顺序输出，B03 仍按标识查找并核对 `options[i]`，不得按注解遍历顺序或坐标排序绑定答案。

### 4.3 归一化定义（`anchorScheme = pageTopLeftNormalizedV1`）

- `pageIndex` 固定**从 0 开始，相对于该题 `PdfPath` 指向的逐题 PDF**。第一页为 0，第二页为 1。
  PdfPig 的 `page.Number` 从 1 开始，写产物时减 1；Windows.Data.Pdf 的 `GetPage(pageIndex)` 直接使用该值。
- 几何输入统一取 `AnnotationDictionary` 中尚未变换的原始 `/Rect`。四个数先取横纵 min/max，再构造四角。
  **不得将 `Annotation.Rectangle` 当作原始 `/Rect` 再裁剪、旋转**。PdfPig 0.1.16 已对该属性应用初始矩阵。
- 有效显示框取该页 CropBox 与 MediaBox 的交集，缺少 CropBox 时使用 MediaBox；继承的页框和 Rotate 也须解析。
  页框宽高必须为正。原始坐标和页框使用同一单位，不混用 TeX pt、像素或已缩放的尺寸。
- 设有效显示框左下角为 `(cx, cy)`、宽高为 `(cw, ch)`。对每个原始角点 `(px, py)`，先算
  `u = (px - cx) / cw`、`v = (py - cy) / ch`，再按 PDF 顺时针 Rotate 转成左上角归一化坐标。

| Rotate | 角点的 `(X, Y)` |
| --- | --- |
| 0 | `(u, 1 - v)` |
| 90 | `(v, u)` |
| 180 | `(1 - u, v)` |
| 270 | `(1 - v, 1 - u)` |

四角变换后取 `x = min(X)`、`y = min(Y)`、`width = max(X) - x`、`height = max(Y) - y`。
所有数必须有限，宽高为正，且 `x >= 0`、`y >= 0`、`x + width <= 1`、`y + height <= 1`。
有效框外的标签失败，不通过裁掉标签或钳位到边界隐藏异常。页索引须小于该题 PDF 实际页数。

B03 以实际显示的 PDF 页面图像左上角为原点，按该图像宽高缩放矩形，默认圆心取矩形中心。
控件容器的留白、滚动偏移和 DPI 变换须另行计入；圆钮直径及命中范围由 B03 决定，不改写坐标产物。
仍需 D/B 实测旋转 `0/90/180/270` × 裁剪「无 / 带偏移」，以及多页、缩放、滚动和不同 DPI 下的点击绑定。

核对依据为 [PdfPig 注解变换](https://github.com/UglyToad/PdfPig/blob/v0.1.16/src/UglyToad.PdfPig/Annotations/AnnotationProvider.cs)、
[页面初始矩阵](https://github.com/UglyToad/PdfPig/blob/v0.1.16/src/UglyToad.PdfPig/Graphics/OperationContextHelper.cs) 与
[Windows.Data.Pdf 页索引](https://learn.microsoft.com/en-us/uwp/api/windows.data.pdf.pdfdocument.getpage)。
本次核对了源码语义，尚未独立执行旋转和裁剪的 PDF 抽取实验。

### 4.4 产物形态

选项定位区域**不写入源侧导入清单**，符合 [逐题显示元数据 schema](../schemas/display-metadata.schema.json)。
学生包中固定为根目录 `option-regions.json`，与 `manifest.json` 和逐题 PDF 放在**同一加密 ZIP** 内，
按 `(examId, paperVersion)` 一起生成、下载、校验和切换，不设学生端明文坐标下载入口。

产物 `artifactVersion` 固定为 1，`anchorScheme` 固定为 `pageTopLeftNormalizedV1`，
考试及试卷版本必须与学生清单一致。每个清单题目及选项恰好出现一次，PDF 路径沿用学生清单的题目映射。
下面是只有 A、B 两个选项的合成题示例，第一页用 0 表示。

```json
{
  "artifactVersion": 1,
  "anchorScheme": "pageTopLeftNormalizedV1",
  "examId": "synthetic-contract",
  "paperVersion": 3,
  "questions": [
    {
      "questionId": "q-001",
      "options": [
        { "optionId": "A", "pageIndex": 0, "x": 0.2239, "y": 0.1900, "width": 0.0197, "height": 0.0212 },
        { "optionId": "B", "pageIndex": 0, "x": 0.2239, "y": 0.2200, "width": 0.0197, "height": 0.0212 }
      ]
    }
  ]
}
```

**上述布局尚未由当前程序实现。** 现有 `StudentPackageBuilder` 不生成坐标文件，
`StudentPaperPackage` 严格核对 ZIP 文件集合，`StudentPackageLayout.IsDisplayPath` 也不接受 JSON 显示资源。
不能只把坐标文件塞进现有包或加入 `DisplayResources`，更不能为此放宽所有未知文件的校验。

后续实现采用学生清单 `schemaVersion = 2` 表示必须附带该坐标文件。它与坐标文件的 `artifactVersion = 1`
是两个独立版本字段，既有 HEXAMPKG 加密信封格式不因新增包内文件而修改。
当前学生清单 schema v1 及现有产物保持原义，本 PR 不提前修改运行时代码或 schema。
D03 与 B03 的接入 PR 必须同步完成以下工作。

- 组包器、公共 DTO/schema、包内文件允许清单和学生读取器一起支持 v2，坐标文件只作为专用元数据接受，
  继续执行 UTF-8、重复 JSON 字段、有限数值、容量、文件集合和考试/版本匹配校验。
- B03 在完整验证题目、选项、页码和 PDF 映射后启用控件。v2 缺坐标或坐标无效时整包失败；
  v1 不猜测点击位置，不宣称具备坐标作答能力。学生端显示更新与读取器的部署版本须匹配。
- 新旧版本产物各自保留，PDF、清单和坐标原子切换；新包失败时保留可恢复旧包及答案，禁止混用不同版本的坐标。
  D03 实现发布前完成组包、加密、学生解密、校验及 B03 点击的接入验证。
