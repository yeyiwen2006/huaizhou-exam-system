# 服务器管理

考务登录后可直接进入“服务器管理”，不再输入第二次账号和密码。页面提供服务器状态、状态检测、服务器配置、操作与事件日志、备份与恢复及请求处理状态查询。主备管理提供状态、醒目的“接管为主服务器”按钮、旧节点重建和保护核对；单节点业务自动可用，取消单机应急按钮。

管理会话由当前业务令牌安全换取，服务端核对已登录账号和权限。退出考务、切换账号或业务会话失效时清除旧管理权限。返回业务页面不会丢失尚未确认的操作记录；已知主备降级警示仍按服务器保护证据解除。

GUI 源文件链接共享 `LocalManagementClient.cs`，没有 SQL、SCM 或备份执行入口。正式持久协调与部署见 [管理契约](high-availability-management.md)。

## 操作流程

1. 先登录考务端，再进入“服务器管理”。考务端可以和服务器位于不同设备。地址与内部标识放在默认折叠的“连接设置（部署人员）”中，缺少配置时可导入部署人员提供的连接文件。连接使用 HTTPS，证书须受考务电脑信任，域名或 IP 须与证书匹配。
2. 页面统一显示一个服务器状态，取值为“服务器已停止”“服务器程序正常运行”“服务器程序运行异常”或“服务器程序状态未确认”，不再分别展示进程、业务就绪和代次。详细检测结果保留连接、材料、证书等实际情况，内部继续核对代次与版本。
3. “状态检测”检查当前配置和运行条件。“服务器配置”使用“服务器地址”“服务器业务HTTPS端口”“数据存储目录”三个字段，不显示版本行。保存仍携带读取版本，冲突时保留表单，重新载入并确认后再提交；后端继续执行停机、权限和路径检查。
4. “备份与恢复”中填写服务器上的备份来源目录，由服务器读取备份信息，无须手填备份标识。点击“按此备份恢复”后，确认框展示所选来源及恢复限制。操作沿用现有恢复流程，旧备份缺少后续最新已确认数据时会阻止开放业务，保留后续已确认数据的保护要求。单一阶段栏按实际进度显示准备副本、核对条件、检测恢复后业务及就绪；失败、核对不通过或尚未就绪时不显示完成。页面不提供业务启停、原内容重试或恢复续行按钮，这些运维操作由正式管理 API 和 CLI 完成。
5. 主备变更先查询最新状态，填写已配置目标及原因，再确认影响。接管时须明确确认旧主断电或业务网络隔离。业务登录不可用时，从登录页“服务器管理 / 故障接管”直接进入，使用原考务账号独立登录目标备机。
6. 接管自动读取新的部署选择、启动业务并检查就绪；一般业务启停和备份恢复续行保留管理 CLI。重建继续保留旧数据隔离副本，禁止回灌旧库。
7. “查询请求处理状态”默认查询最近一次操作，也可以输入历史请求编号。响应丢失、取消等待或重启后仍使用原请求编号查询；查询不重新执行操作。页面不再单列待核对请求，处理情况由操作结果展示；原请求记录仍保留，防止重复提交。

管理页面中的服务配置不包含秘密，也不保存考务密码。换取的管理令牌只保留在当前连接内存中，退出、账号切换或释放连接时清除，界面无法继续使用旧管理身份。

## 首次部署连接配置

考务端优先读取当前 Windows 用户保存的管理连接；没有用户记录时，自动读取 `Exam.Admin.exe` 同目录的 `management-connection.json`。连接文件仅包含 `address`、`serverId`、`nodeId` 三个字段，不含账号、密码、数据库连接串或证书私钥。界面导入后保存到当前用户的管理记录目录，下次考务登录后继续使用。

部署人员在管理服务所在机器上，根据实际生效的管理配置生成连接文件。以下命令中的路径须替换为本机部署位置；若管理配置由多个来源合并，输入文件中的 `Management.HttpsPort`、`Management.ServerId` 和 `Management.NodeId` 须与服务最终生效值一致。

```powershell
pwsh -File deploy/management/Export-AdminConnection.ps1 -ManagementConfigurationPath "C:\Exam\Exam.Management\appsettings.json" -AdminDirectory "C:\Exam\AdminConnection" -HostName "manage.exam.example.invalid"
```

导出时用 `-HostName` 指定考务电脑能够访问的管理域名或 IP。工具仅把地址、服务器标识和节点标识写入连接文件，不复制完整部署配置。将生成的 `management-connection.json` 交给考务人员，通过“导入连接配置”导入，或放在考务端程序旁。业务地址与管理地址分别配置，管理服务使用独立监听端口；端口随连接文件分发，考务人员登录时无须填写。

已有用户记录优先于随安装提供的配置；更换管理端口或节点时，重新导入连接文件，或在折叠区由部署人员修改并保存。无效导入不会替换原连接。生成的 `management-connection.json` 已从 Git 和两个源码目录的同步中排除。

在服务器上显式设置 `Management:BindAddress` 为可接收远程连接的网卡 IP，或 `0.0.0.0`，并为管理端口配置防火墙访问范围。未设置时仍只监听本机。管理页面中的数据目录、备份目录和工具目录均属于目标服务器，例如 Windows 的 `D:\Exam\data` 或 Linux 的 `/srv/exam/data`。正式部署流程见[服务器部署](../deploy/server/README.md)。

正式管理 API 和 CLI 保留独立账号登录、业务启停、原请求重放及恢复续行。Windows 管理服务保留经数据库核对的账号加密缓存，数据库暂不可用时可用于独立管理登录。Linux 不保存离线缓存，管理认证需要数据库可达。Linux 支持状态、状态检测、配置、启停、日志和备份，隔离恢复及主备变更继续使用 Windows 部署。正常 GUI 复用考务会话；业务不可用时提供独立管理登录以完成接管。独立登录仍由管理服务验证原账号和权限。

## 持久请求与警示

变更发送前，在当前 Windows 用户 DPAPI 下保存原请求、目标、已认证操作者和内容摘要。一个节点只保留一个未解决请求；独占锁和原子移动防止其他考务实例覆盖。损坏、写入失败或链接路径阻止发送，不删除待核对记录。记录不包含口令、会话、响应体、试题或原始日志。

短读取和最长 65 分钟变更分别设定期限。离开页面停止读取与等待，保留原请求；旧连接响应不能改变当前页面。原请求轮询最多 10 次，每次间隔 2 秒，只查询、不重发、不重叠。确认终态前核对请求、目标、操作者、类型、摘要和阶段证据。

主备状态超过 10 秒或缺证据时显示未核实，禁止新的主备变更。解除警示须有当前状态、实际复制、材料、证书和双侧最新持久确认，零延迟不能替代。每个目标的降级警示另用 DPAPI 保存，记录损坏保留警示。“操作与事件日志”显示请求编号或事件编号、类别、阶段或事件级别、结果，每类最多 50 条，只展示固定元数据，不读取任意文件或原始消息。

已显示的保护证据也会按时失效，不依赖下一次网络响应。重新登录或重启后，低于已保存代次、版本或同版本核实时间的响应不能解除单份数据警示。检查名称、日志来源/级别和隔离确认采用中文，时间按 UTC+8 显示。

## 验证与运行边界

```powershell
dotnet restore Huaizhou.ExamSystem.sln --locked-mode
dotnet build Huaizhou.ExamSystem.sln --no-restore --configuration Release
python eng/testing/run_checks.py --profile core --profile wpf --output .artifacts/management/final
python eng/testing/run_checks.py --profile postgres --profile postgres-physical --postgres-bin <tool-directory> --native-physical --output .artifacts/management/final-postgres
```

管理接口、持久请求及数据库恢复分别使用对应分类测试。当前尚未操作真实服务器；真实显示器 DPI、服务账户、现场证书、两台独立主机网络和断电恢复仍需在目标环境验收。

## 恢复与回退

回退界面前保留加密原请求、保护警示和服务端日志。已提升或重建后不能靠代码回退撤销角色；禁止自动切回或合并旧库。根据实际持久代次与隔离证据选择恢复方式。
