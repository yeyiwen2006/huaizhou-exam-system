## 当前行为

| 项目 | 实现与边界 |
| --- | --- |
| 源侧依赖 | 读取文档类、宏包、字体、图片、自定义图片宏及搜索目录，识别 RequirePackage、LoadClass 和不带花括号的 input |
| 编译前检查 | 遍历包内 TeX、sty、cls、def、cfg 文件，拒绝已识别的外部命令、越界引用、直接文件读写流及所有重解析点 |
| 图片检查 | 工作目录优先，再按 graphicspath 检查；支持子目录引用和省略常见扩展名；搜索目录必须使用有效目录名 |
| 编译目录 | 包根仍是进程工作目录；每次在 OutputDirectory 下新建 compile 子目录，调用方使用返回的 OutputPdfPath |
| 成功条件 | 退出码为零、未超时、日志完整且无阻断问题、此次调用确实产生非空 PDF；失败不返回 PDF 路径 |
| 字体与错误 | 缺宏包、字体、图片和普通排版错误均阻断；默认字体替换、缺字警告也阻断；保留日志能给出的行号 |
| 外部命令 | 关闭 shell escape，MiKTeX 另关闭 write18 和自动安装；按发行版关闭首行选项解析；源文件参数加相对路径前缀 |
| 资源 | 默认 120 秒，允许 0 至 6 小时之间的正时限；每 100 ms 采样主进程工作集与本次输出目录，阈值分别为 1 GiB、128 MiB；超限终止进程树 |
| 输入与日志 | 最多 10000 个包内条目，单个 TeX 源不超过 8 MiB；日志超过 8 MiB 直接失败；标准输出、错误输出各捕获最多 64 KiB |

输入路径、输出路径越界或经过联接时抛出参数或权限异常，调用方须把这些异常显示为导入失败。
缺依赖、超时、资源超限和实际编译错误返回失败结果。失败目录由导入任务负责清理，不能当作可预览或可发布的版本。
TryDetect 只搜索可执行文件，发行版必须由调用方明确提供，不能把任意 PATH 中的 xelatex 都当成 MiKTeX。

## 审查修正

- 编译入口现在实际执行静态检查，包内嵌套样式和图片联接不能绕过检查。绝对路径的前导分隔符在校验前保留。
- 重试、同名题目与并发调用各用独立输出目录，已有 PDF 和日志不能让新请求误判成功，也不会被覆盖。
- 补充默认字体替换和缺字的日志识别；普通源错误保留行号；已有阻断问题才把连带错误标记为非独立问题。
- 日志折行处理去掉逐行复制整个缓冲区的开销；超长日志不能只读取成功前缀后通过。
- 运行期间监控内存和输出空间；超时、取消、超限或监控异常都会清理进程；处理临时文件消失与进程自然退出的竞态。
- 合约新增 ResourceLimit 枚举值并追加在末尾；共享进程运行器新增可选资源限制参数，既有备份调用保持兼容。

## 使用限制与后续任务

- 静态检查及进程监控用于考务提供的导入材料，不是任意恶意 TeX 的操作系统沙箱。引擎级文件限制随发行版而异，不能把 TeX Live 的环境变量当作 MiKTeX 同等隔离的证明。
- 内存和空间限制采用采样，存在一个采样间隔的超出量；内存指标是主进程工作集，不是整个进程树的硬配额。调用方负责总体并发、队列和长期失败目录清理。
- 日志无法可靠确定的定位信息保持缺省，缺宏包时至少给出准确依赖名，不伪造声明行。需要完整 TeX 语义展开的依赖仍以真实编译结果为准。
- 作者此前报告了 MiKTeX 26.5 上原版 5 项真实编译测试；本次修正版在 TeX Live 上实测，未在本机重复验证 MiKTeX。
- C05 #21 跟踪导入预览、发布和 GUI/CLI 接入，D06 #29 跟踪真实试卷对照及编译 CLI。三校真实材料、完整学生包发布、300 人规模和现场环境不在本次验收结论内。
