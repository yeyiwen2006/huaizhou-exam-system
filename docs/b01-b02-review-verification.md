## B02

已完成以下代码复核及修正：

- 用真实 HTTPS API、SignalR 和共享 HEXAMPKG v2 实现替换生产 Mock、模拟 START 与独立合成题包格式。
- 准备、下载、说明与确认参试按同一套版本核对；服务端事务核对当前时间和设备授权，锁等待及解封耗时也不能越过发钥截止时间。
- 所有设备拒绝响应使用一致的错误契约；显式授权撤销与一般网络故障分开处理。
- 未决确认、退出和 ACK 保留原请求标识，重启后先查明结果；恢复不凭本地缓存单独获取答题权限。
- 题包临时写入完整且刷新后才发布；损坏包可重新下载。恢复记录和密钥材料受当前 Windows 用户 DPAPI 保护，题目明文不落盘。
- END 保持终态；解锁与撤销/结束并发时，已过期的解锁返回不能重新发布明文。
- 真实 SignalR 复现并修正了慢 START 阻塞后续 END/授权撤销的问题。接收回调快速返回，处理任务有界、同事件去重，END 保留独立处理容量；关闭连接时等待在途工作，CatchUp 同批终态优先。
- 考试说明历史版本、原等待登记恢复、已结束考试补传准备及授权拒绝都有回归测试。
- 答题、保存及交卷模块尚未接入的按钮保持禁用，不生成假答卷或假回执。
