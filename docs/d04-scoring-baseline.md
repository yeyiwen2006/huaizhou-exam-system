# D04 精确计分人工核算基准

本文给出可**手工逐行核对**的计分样例，供 A 审查与 E 独立核算使用。全部为**合成**考试，
规则形状取自 `requirements.md`「考试配置与计分」的两组示例，不含任何真实试卷内容。
每一行都对应 `tests/Unit/Exam.UnitTests/Scoring` 下的自动化用例，文档与代码必须一致。

## 1. 交大式错扣分（一个正确选项）

规则：`oneCorrect = { correct: 3, blank: 0, wrong: -0.75 }`，选项 A、B、C、D，正确答案 A。

| 作答 | 判定 | 逐题分 | 依据 |
| --- | --- | --- | --- |
| 选 A | 选对 | `3` | 与答案完全一致 |
| 空选 | 不选 | `0` | 不选走 blank |
| 选「不作答」 | 不选 | `0` | 与空选同走 blank，但学生端颜色不同 |
| 选 B | 选错 | `-0.75` | 选到错误选项 |
| 选 A、B | 选错 | `-0.75` | 含错误选项即选错，不是部分选对 |

## 2. 单科归零（小题负分先相加，再按科目归零）

规则同上，三道题同属科目甲，正确答案都是 A。

| 题号 | 作答 | 逐题分 |
| --- | --- | --- |
| 1 | 选 A | `3` |
| 2 | 选 C | `-0.75` |
| 3 | 选 D | `-0.75` |

- 科目甲原始分 = `3 - 0.75 - 0.75` = **`1.5`**（先相加）
- 科目甲最终分 = `1.5`（非负，不归零）
- 若三道题全部选错：原始分 = `-2.25` → 最终分 **`0`**，且该负分**不抵扣其他科目**

## 3. 清华式按正确选项数量计分（含变量）

规则：`oneCorrect = { correct: {正确选项总数}, blank: 0, wrong: 0 }`、
`multipleCorrect = { allCorrect: {正确选项总数}, partialCorrect: {选择的正确选项数}, blank: 0, wrong: 0 }`，
正确答案 A、B、C（3 个正确选项）。

| 作答 | 选对个数 k | 判定 | 逐题分 | 算式 |
| --- | --- | --- | --- | --- |
| A、B、C | 3 | 全部选对 | `3` | `{正确选项总数}` = 3 |
| A、B | 2 | 选对但不全 | `2` | `{选择的正确选项数}` = 2 |
| A | 1 | 选对但不全 | `1` | 同上 |
| 空选 | 0 | 不选 | `0` | blank |
| A、D | 1 | 选错 | `0` | 含错误选项 D |

注意：该题满分随题目变化（等于该题正确选项数），因此**题组与科目满分必须由逐题求和校验**，
配置不符不得发布 —— 这条求和校验在 D01 的清单校验器里（需同时持有清单与答案）。

## 4. 发布前必须拒绝的规则

| 规则 | 为什么拒绝 | 期望规则码 |
| --- | --- | --- |
| `correct = 1/3` | 最终分值不是有限小数（`requirements.md`：1÷3 必须拒绝发布） | `score.notFiniteDecimal` |
| `blank = 1/{选择的正确选项数}` | 不选时 k=0，代入分母为 0 | `score.divisionByZero` |
| `partialCorrect = 2/{选择的正确选项数}` | 正确选项 4 个时，k=3 会得到 `2/3`（非有限小数）——**只抽查一个 k 会漏** | `score.notFiniteDecimal` |
| `correct = {总题数}` | 变量不在白名单内 | `score.expressionUnknownVariable` |
| `correct = -1` | 满分为负 | `score.negativeFullScore` |
| 参考答案含未声明的选项 `E` | 答案与题目选项不对应 | `score.correctOptionNotDeclared` |
| 该题 2 个正确选项却只配 `oneCorrect` | 缺所需分支 | `score.branchMissing` |

## 5. 精确性与显示

| 检查 | 期望 | 说明 |
| --- | --- | --- |
| `0.1 + 0.2` | `0.3` | 用 BigInteger 分子分母精确计算，不走 double |
| 整数分 | `3` 而不是 `3.0` | 整数不带小数点（`requirements.md`） |
| 中间值 | 保留精确分数 | 只在最终显示时转成有限小数字符串 |

## 6. 人工核算方法

1. 逐题判定：空选与「不作答」同走不选；选到任一错误选项即选错；与答案完全一致为选对/全部选对；
   其余（答案的非空真子集）为选对但不全。
2. 逐题代入对应分支的表达式，取与「正确选项总数」和「选择的正确选项数」的精确值。
3. 按科目把逐题分**先相加**得到原始分；负的原始分记为 0，不抵扣其他科目。
4. 总分为各科最终成绩之和（各科最终分均不小于 0，因此总分也不小于 0）。

以上四步与代码一一对应：`ScoreCalculator.DetermineOutcome`、分支求值、单科归零、总分。
`ScoreCalculator.ValidatePublishable` 负责在发布前枚举每题**所有可达**的作答情形并逐个检查。
