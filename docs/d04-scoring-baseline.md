# D04 精确计分人工核算基准

本次交付纯逻辑计分和逐题发布前校验，关联 PR #51、Issue #27。全部样例使用合成题目，计分规则取自 requirements.md。A 已对作答枚举和异常输入进行审查修正。

## 一个正确选项

选项为 A、B、C、D，参考答案 A。选对得 3 分，空选得 0 分，选错扣 0.75 分。

| 作答 | 判定 | 逐题分 |
| --- | --- | --- |
| A | 选对 | 3 |
| 显式 Empty | 不选 | 0 |
| 已启用的不作答 | 不选 | 0 |
| B | 选错 | -0.75 |
| 不定项题选 A、B | 选错 | -0.75 |
| 单项题选 A、B | 非法输入，整体计分失败 | 无分数 |

QuestionRule.Type 必须从对应题组传入。其兼容默认值为 Indeterminate，单项和多项题接线时不能省略。AllowAbstain 从题组传入，默认 false；未启用时收到 Abstain 属于非法输入。

## 小题负分先相加，再按科目归零

同科三题按上表计分，依次选择 A、C、D。原始分为 3 - 0.75 - 0.75 = 1.5，最终分为 1.5。

若科目甲原始分为 -0.75、科目乙为 3，甲最终记 0，乙记 3，总分为 3。科目甲的负分不抵扣乙科。

## 多个正确选项

选项为 A、B、C、D，参考答案 A、B、C。全部选对得 {正确选项总数} 分，选对但不全得 {选择的正确选项数} 分，空选及选错得 0 分。

| 作答 | 选对个数 k | 判定 | 逐题分 |
| --- | --- | --- | --- |
| A、B、C | 3 | 全部选对 | 3 |
| A、B | 2 | 选对但不全 | 2 |
| A | 1 | 选对但不全 | 1 |
| Empty | 0 | 不选 | 0 |
| A、D | 1 | 选错 | 0 |
| A、B、C、D | 3 | 选错 | 0 |

多项及不定项题存在错误选项时，选错分支的 k 必须覆盖 0 至正确选项总数，含两端。原实现漏掉最后一种情况。单项题选错时 k 只能为 0，不能把多选情形放进它的发布校验。

## 发布前拒绝的规则

| 输入或规则 | 原因 | 规则码 |
| --- | --- | --- |
| correct = 1/3 | 最终分值不是有限小数 | score.notFiniteDecimal |
| blank = 1/{选择的正确选项数} | 空选时 k 为 0，发生除零 | score.divisionByZero |
| partialCorrect = 2/{选择的正确选项数}，四个正确选项 | k 为 3 时得到 2/3 | score.notFiniteDecimal |
| wrong = 1/({正确选项总数}-{选择的正确选项数})，不定项且存在错误选项 | 选齐正确选项并加选错误项时除零 | score.divisionByZero |
| correct = {总题数} | 变量未定义 | score.expressionUnknownVariable |
| correct = -1 | 满分为负 | score.negativeFullScore |
| 答案包含未声明的 E | 答案与选项不对应 | score.correctOptionNotDeclared |
| 缺少参考答案 | 不能发布无答案题目 | score.correctOptionMissing |
| 多个正确选项却缺少 multipleCorrect | 缺所需分支 | score.branchMissing |
| 重复题目、重复选项、重复答案或题型与答案数量不符 | 规则集合无效 | score.ruleInvalid |

题组和科目满分逐题求和仍由 D01 的清单及独立答案校验完成。发布调用点必须同时通过 D01 与 D04，单独调用逐题校验不能证明整卷满分正确。

## 冻结答卷输入

Grade 要求题目记录与规则一一对应。未作答显式使用 AnswerValue.Empty()；缺失记录、额外题目、重复或未知选项、无效作答类型、单项题多选和未启用的 Abstain 均导致整体失败，不返回任何分数。DetermineOutcome 直接收到这些无效输入时抛出 ArgumentException。

A05 的 SubmissionPolicy 目前只检查提交项的基础结构，未保证与题目清单完整对应。因此不能依赖它省略计分侧的检查。后续接线必须明确保证冻结记录完整，不能在计分时补造 Empty 掩盖漏传。

所有分数由既有 ExactRational 和专用表达式解析器计算。0.1 + 0.2 得 0.3，整数 3 显示为 3；不使用浮点或四舍五入补偿。单科和总分由通过逐题有限小数检查的精确值相加得到。
