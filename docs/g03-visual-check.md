# G03 独立控件合成视觉检查

> 来源：G03 五类表格清单、`ReportWorkspaceView`、`ReportTableView` 与本地离屏 WPF 实测。以下只有合成样例，非真实考生、真实考试或正式服务响应；团队仅用 A—G 代号。

## 检查输入与方法

- Windows、.NET SDK 10.0.401；按锁文件还原并用 Release 构建。
- 构造 1 科 40 题、30 名合成考生；每题满分 5，答案为标注“合成答案”的长文本。由 G01 纯计算产生完整结果，再交给 G03 会话层和组合视图显示。
- 分别将 WPF 逻辑视口设置为 `1366×768`、`1366/1.25×768/1.25`、`1366/1.5×768/1.5`，按 96、120、144 DPI 离屏渲染为 1366×768 PNG。这是布局模拟，不等同于系统显示设置中的实际 125%/150% 缩放。
- 100% 与 150% 显示小题得分表，检查固定均分行、颜色和纵横滚动；125% 显示答案表，检查无均分行、长文本省略显示，并在已实现的单元格上核对悬停提示保留完整答案文本。
