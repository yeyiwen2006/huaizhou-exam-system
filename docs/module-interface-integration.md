# 已有模块的接口衔接

本次修正接续 PR #50 和 #51，解决学生答卷稀疏记录与严格计分输入之间的冲突，并连接学生包读取、导入规则组装和计分发布校验。Issue #26、#27 继续跟踪各自未完成的功能。

## 学生包和题目清单

D03 先验证服务器导入清单，再生成学生专用 StudentPaperManifest。ZIP 内仍使用 manifest.json，但内容由 [student-paper.schema.json](../schemas/student-paper.schema.json) 定义，与导入清单分开。字段仅包含考试、试卷版本、科目、题组、题目结构、PDF 路径、显示选项及经确认的附加资源。

[合成清单示例](../samples/synthetic/minimal/student-manifest.example.json) 展示序列化格式。该文件是独立的契约示例，引用的 PDF 需经编译生成，并非可以直接下载的学生包。参考答案、计分公式和 TeX 源路径不进入学生显示清单。

StudentPaperPackage 在内存中验证 ZIP 文件列表和清单。它拒绝缺失 PDF、重复路径、大小写冲突、越界路径、未声明文件、重复 JSON 字段以及考试或试卷版本不匹配。清单上限为 8 MiB，ZIP 和解压文件合计各不超过 256 MiB，文件数上限为 10000。

PR #53 整合后，读写两端共用 StudentPackageLayout 的容量、PDF 映射、规范路径及文件头规则。学生端逐段读取全部显示文件，拒绝只有合法文件头而正文不完整的内容；明确列入显示清单也不能放行服务器专用路径、答案资源或非显示文件。路径最长 512 个字符，各段按 Windows 文件名限制验证。读取可取消，验证后的清单和选项集合不可修改。

StudentExamRuntime 在服务器授权及解锁后读取此清单，再启动本地答题会话。B03 可通过 Paper 读取结构，通过 ReadQuestionPdf 取得指定题目的 PDF。调用者负责释放显示副本，结束或撤销授权后不能重新取 PDF。选项坐标尚未生成，接口没有虚构可点击区域，完整 WPF 答题页面仍待实现。

包解析在工作线程执行。解析完成后重新核对载荷、授权、服务器身份及试卷版本，结束、撤权、关闭会话或版本切换期间取得的旧结果不能创建新答题会话。保存和冻结继续使用原 SQLite 串行事务路径，冻结前再次核对答卷完整性。

旧 D03 包内使用导入清单，缺少当前学生清单所需的试卷版本和 PDF 映射，不能直接使用。需要用新构建器生成新产物路径，再沿用现有发布及版本核对流程。已有密文和学生本地记录均不覆盖。

## 完整答卷

学生端只在没有既有记录、已取得当前授权并验证题目清单后，为每题建立显式 Empty。修改答案保留其他题目，固定时保存完整快照。恢复时发现缺题、陌生题目或非法选项会停止作答，保留原 SQLite 记录，不补造答案。已固定的旧答卷仍优先恢复和保留，严格计分若发现残缺会报错，不能将其冒充有效分数。

生产 SubmissionService 从 IExamVersioningService 读取已发布的 PaperStructure，在保存新进度和新答卷前执行 AnswerSheetContract。其题目编号、题型、选项和 AllowAbstain 与学生清单来自同一导入映射。AllowAbstain 加入 PaperQuestionStructure，旧序列化数据缺少该字段时取 false；开考后更改这一约定也属于不允许的结构变更。

已经持久保存的答卷继续由原事务存储核对身份和授权，重复请求返回原回执，不覆盖原答案。没有发布清单的新答卷会被拒绝。底层独立存储测试可省略清单读取器，生产注册始终提供；其他新调用点也必须提供清单。

## 导入、发布和计分

ImportedGradingRules.Create 同时读取 D01 清单与完整独立答案，执行清单结构、题组和科目满分核对，以及 D04 对全部可达作答情形的检查。它按题目映射题组计分规则，明确传入 Type 和 AllowAbstain，不使用默认题型代替真实配置。

现有 POST /api/v1/versioning/exams/{examId}/grading-publications 增加 manifestJson 和 answerKeyJson 两个输入字符串。HTTP 新发布必须提供两者，服务端重新校验，并确认与已发布试卷一致。客户端原有 validation 标志仍须满足既有流程条件，但不能代替数据校验。

为使旧 PostgreSQL 命令流继续可重放，内部 PublishGradingRulesRequest 的新增字段允许省略。新 HTTP 请求不能走这一兼容路径。带源数据的新命令在现有服务器数据库事件中保存，重启后仍能重放校验；响应和版本快照仅保留原发布信息，不返回参考答案。操作仍由现有考务身份边界控制。

ImportedGradingRules.Grade 接收 A05 的 FinalSubmission 和目标计分版本，核对考试及原回执关联，再调用精确计分。它只读原答卷，失败时不生成分数。D05 的后台消费、成绩持久化和重算尚未实现，本次没有启动自动评分服务，也没有修改数据库表结构。

## 验证与恢复

合成用例贯通 D03 组包加密、学生解密与读取、真实 SQLite 保存、部分作答、固定答卷、A05 收卷回执及 D04 计分。三题型合成清单全对为 37 分。真实 TeX 用例将两个独立目录的编译结果组包，再由学生读取器读取 PDF。

错误路径覆盖残缺本地记录、损坏 ZIP、错考试和版本、非法作答、缺参考答案、满分不符、隐藏除零及发布结构不匹配。回归保留原有撤权、结束、保存恢复和重复交卷测试。PostgreSQL 重放检查交由独立数据库 CI 执行。

回退时应将构建器和学生读取器作为同一契约版本处理，不覆盖旧密文和本地答卷，也不改写已固定记录。未完成的坐标、实际界面、自动评分、真实设备、多机及 300 人场景仍需后续验收，本次结果不代表 T01/T02 通过。
