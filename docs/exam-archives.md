# 单场考试数据导出与导入

考务端“全部考试”中的每张考试卡片提供“导出本次考试的全部数据”。选择这台考务电脑上的保存目录后，程序在其中新建带考试名称和时间的子目录，保存 `exam.archive`。把整个子目录复制到另一台考务电脑，就可以向另一台服务器导入。

导出是复制。原服务器上的考试、考生登录和答卷不会被删除或修改，原考生可以继续作答。归档保存读取时刻的数据；读取之后原服务器收到的答案和其他变更不会自动加入已导出的文件。

## 归档范围

归档包含考试设置、名册、试题及资源、试卷与评分规则的版本记录、参加记录、已有作答进度、已交答卷、成绩，以及与本场考试关联的操作记录。它不包含全局考务账号、服务器密码、证书私钥或原服务器的可用学生登录凭据。

题包会转换成可移植内容，在目标服务器导入时重新建立考试和资源关联，并使用目标服务器的题包证书加密。因此，导入不需要原服务器的磁盘目录、原考务电脑或原服务器私钥。目标服务器仍须完成本系统正常部署所需的题包证书配置。

归档含试题、答案和考生数据，应保存在有相应访问权限的位置。当前格式版本为 1，单个 `exam.archive` 的上限为 512 MiB；超限会明确报错，不会把未完成文件显示为导出成功。

## 添加考试与重复处理

“全部考试”顶部使用“添加考试”入口，提供“新建考试”和“从目录导入考试数据”。导入时选择包含 `exam.archive` 的目录，程序通过当前考务连接上传，所选目录不需要存在于服务器上。

系统按归档保留的考试来源标识判断是否已存在同一场考试。同名但来源不同的考试不会自动被覆盖。发现同场考试时，对话框显示考试名称并提供三个选项：

- **覆盖原考试**：用归档替换所选目标考试的本场数据。其他考试、全局考务账号和服务器配置不受影响。若目标考试在预览后发生相关版本变化，需要重新预览再确认。
- **作为新副本导入**：分配新的考试标识，保留归档数据。名称已被占用时自动添加副本后缀。
- **跳过该考试导入**：保持目标系统现状。

没有同场考试时直接作为新副本导入。成功后可进入该考试查看答卷和成绩，并按现有业务规则继续使用；曾经开考的考试仍保留既有试卷结构限制。

原考生继续在原服务器作答。需要使用目标服务器上的副本时，考生在目标服务器独立登录，已有参加记录按正常设备授权流程处理，不沿用原服务器登录凭据。

源服务器尚待处理的换机申请保留为历史记录，目标服务器根据当前登录设备重新处理。历史学生端编号没有冲突时沿用；与目标系统既有编号冲突时分配独立编号，并保留原编号记录。

## 接口与文件

这些接口均要求已登录的考务账号：

| 接口 | 用途 |
| --- | --- |
| `GET /api/v1/exams/{examId}/archive` | 下载单场完整归档 |
| `POST /api/v1/exam-archives/preview` | 上传归档文件并读取同场考试列表 |
| `POST /api/v1/exam-archives/import` | 按副本、覆盖或跳过方式处理归档 |

预览和导入使用 multipart 的 `file` 字段。导入还接收 `requestId` 和 `mode`；覆盖时提供预览返回的 `expectedTargetExamId`、`expectedTargetVersion`。导入请求保留处理回执，同一请求重试不会创建第二份副本。

`exam.archive` 是本系统的版本化 ZIP 容器，包含 `manifest.json` 与 `content/` 下的资源。它不是服务器全库备份，不能通过“服务器管理”的备份恢复入口使用，也不要手工修改其中的标识和关联数据。
