# B01 实施状态

本次修订已对齐最新 A 组服务器代码。正式学生端只连接配置的 HTTPS 服务器，不加载演示考试或模拟批准结果。

## 已完成的代码

- 共享浅色主题、页头、按钮、校验输入、表格、状态、等待遮罩、确认弹窗及组件样例页。激活前显示“未激活”，激活后显示服务器编号，姓名随登录切换。
- 激活、登录、考试选择与后续页面外壳。考试列表从当前设备绑定的真实会话及名册查询，显示名称、类别、科目、时间和状态。
- Windows 当前用户 DPAPI 保护设备身份与未完成请求；写盘后才发送激活申请，临时文件强制刷新后原子替换，备份同样加密。旧版明文、损坏文件或身份不符会明确停止，不创建新身份覆盖。
- 首次激活请求丢失响应时重试原请求，取得申请标识后使用状态查询。取消与重新激活保存未决请求，恢复时沿用原设备、编号、凭据和试场；取消未确认期间不能登录。
- HTTPS 客户端校验逻辑服务器、节点及非递减代次，拒绝重定向及切换连接后的旧响应；凭据不放入 URL，不绕过 TLS 证书验证。
- 服务端时间校准，以单调计时推进显示，首次未校准不采用本机墙钟；之后错开首次间隔并每 60 秒校准。
- 服务器新增本人取消激活和名册内考试概览接口。移除可绕过正式交卷事务的公开 finalize 入口，交卷必须经由原子保存答案和回执的 `/api/v1/submissions/final`。

身份保存在 `%LOCALAPPDATA%\HuaizhouExam\Student\devices.protected`。该路径、备份、日志和考试缓存不进入仓库。

## 边界

B01 交付界面与身份入口，不代表已完成正式考试。等待、解锁由 B02 接入；PDF、答案保存、交卷、更新及切主分别由 B03 至 B08 跟踪。未实现操作明确禁用，不显示模拟 START、不生成固定 74 题、不伪造交卷成功。交卷成功页必须接收当前考生的真实服务器回执。

项目负责人已明确取消同学评审这一 B01 关闭前置条件，B01 按已合并代码和通过的测试关闭。当前未执行两端并排及 100%/125%/150% 缩放人工检查；没有把代码构建或单元测试写成人工界面验收。

## 本机验证

- 学生端身份及 HTTP/时钟测试 15/15 通过，覆盖受保护保存、损坏拒绝、重试保号、身份/代次拒绝、凭据请求边界、旧连接响应丢弃与单调校时。
- 服务端激活测试及真实 PostgreSQL 的自助撤销、重启回放、概览会话隔离测试通过；公开 finalize 路由回归通过。
- 测试仅使用独立合成考生、试题和凭据。正式试卷、个人数据、证书私钥及本机连接配置未上传。
