# B03 学生导航显示契约

本次按 requirements.md 的导航示例补齐科目满分、题组序号、题型全称与每题分值。
科目按清单顺序显示，题组按 order 排序，题号按数值升序且跨科不重置。
每个科目的标题只显示一次；题组序号在每科从「一」开始。每行固定十个题号方框。
已作答变绿、私人标记红点、当前题突出显示及手动点击题号跳题保持原有语义。

单选题选中普通选项，以及任何题型选中已启用的「不作答」后，先可靠保存答案，再跳至全卷题号顺序的下一题。
多选和不定项选择普通选项、取消选择、保存失败时不跳题；最后一题停留，不循环或自动交卷。
跳转前再次核对作答状态、授权和当前试卷，继续使用现有的导航保存与题目渲染流程。

## 学生清单 v3

`StudentPackageBuilder` 在接收选项坐标产物时生成 schemaVersion 3，新增两项必填的只读文字。

| 位置 | 字段 | 内容与来源 |
| --- | --- | --- |
| subjects[] | maxScoreText | 科目配置的 maxScore，去掉首尾空白，不带「分」 |
| groups[] | perQuestionScoreText | 本题组满分表达式，带「分」；导航在前面添加「每小题」 |

单选取 oneCorrect.correct，多选取 multipleCorrect.allCorrect。
不定项同时取两分支的满分表达式；两段文字相同时仅显示一次，不同时按单正确、多正确顺序以 `/` 连接。
变量原样显示，不根据参考答案代入。因此 `{正确选项总数}分` 不会暴露某道题的正确选项数量。
不下发评分分支对象、错选、漏选、空白规则或参考答案。

以下为合成清单片段，仅说明新增显示字段，不是可单独导入的完整试卷。

```json
{
  "schemaVersion": 3,
  "subjects": [{"subjectId": "synthetic-math", "name": "合成数学", "maxScoreText": "100"}],
  "groups": [{"groupId": "synthetic-group", "subjectId": "synthetic-math", "name": "不定项选择题", "order": 1, "perQuestionScoreText": "3分/4分"}]
}
```

显示为「合成数学（100分）」和「一、不定项选择题（每小题3分/4分）」。
已有题组名称若带中文或阿拉伯数字序号，先去掉旧序号再按实际顺序生成，避免重复。
常见的「单项选择」「多项选择」「不定项选择」简写补成题型全称，其他自定义名称保留。

## 兼容与恢复

新版读取器接受学生清单 v1、v2、v3。v1/v2 不带新增字段，显示已有科目和题组名称，
不猜测满分；v2/v3 必须附带通过完整语义校验的 option-regions.json。
v3 缺少显示文字或文字为空时拒绝整个包。v1/v2 夹带这些新字段也拒绝。
学生清单版本与选项坐标 artifactVersion 是两套独立版本，不得混用。

先升级学生端与组包服务，再以新的 paperVersion 重新编译、组包和发布。
旧客户端不支持学生清单 v3，会拒绝该版本。已有版本文件不可原地覆盖。
回退时恢复兼容的客户端和已发布旧版本，不能只把 schemaVersion 数字改小；
原有作答和版本切换流程仍由既有服务处理，本次没有数据库迁移或计分计算变更。

## 合成预览

截图夹具只使用合成题目，采用已核对的交大版面参数；题干为一倍行距，选项为二倍行距。
选项标签点号之后另加一个当前字体的普通空格宽度。
Arial 仅用于学生端按钮字母，PDF 字体仍由合成 TeX 控制。预览包含普通选项选中和「不作答」选中状态。
「不作答」文字比本题第一个普通选项按钮大 0.5 磅，去除字间空格，内边距为左右 10 DIP、上下 6 DIP；
按钮左边缘与第一个普通选项按钮的左边缘对齐。
答题页右下角的服务器时间、剩余时间仅显示时分，尚未校时显示「--:--」，内部校时与交卷时机不变。
正式试题及其文件未复制到仓库。
