# G01 计算内核审查边界

2026-09-27，PR #65 的 A 审查。此处只接纳纯计算内核与合成测试，不代表整个 #31/G01、报表 GUI/导出/开放权限或 T01/T02 完成。

## 已核对及修正

- 统一平均分样本：所有科目最终成绩均大于零；个人零分仍保留在个人排名，小题负分不能额外排除该考生。无样本返回空均分和空班级排名，不伪造为零。
- 精确有理数决定排名，采用 1、1、3 制；同分按准考证数值再按原字符串，保留前导零。只在显示边界舍入两位，不按已舍入均分排名。
- 考试、计分版本、参试者、答卷、科目与题目完整性不一致时拒绝输入，不补造缺失成绩。
- 审查新增两项输入一致性约束：科目满分必须等于逐题满分之和；单科最终分必须等于逐题原始分求和后再取最低零。后者是已发布成绩的算术校验，不是按答案重算成绩，也不在报表内引入第二套判分规则。
- 原负分测试的单科 2 分与唯一小题 -1 分互相矛盾，修正为两个小题 -1、3 分，单科仍为 2 分。新增回归验证单科原始和为负、零、正时的归零顺序及精确舍入。
