# C01 考生计分说明预览（2026-10-05）

对应 [C01–C04 剩余业务实现与接线 #46](https://github.com/yeyiwen2006/huaizhou-exam-system/issues/46)，
落实 `docs/reviews/ui-requirements-c-20261002.md` 的**第 2 项**。需求依据：`requirements.md` 第 116、131 行。

## 问题

考务「考试设置」页原先用一个只读文本框显示说明，整段同一种字体，且内容始终由考务端本地重算：
服务器保存的、学生端实际显示的说明文本没有被回显过，两者是否一致无从核对。

## 现在的行为

- **字体**：正文黑体（SimHei）、数字（含小数）Times New Roman。分段规则与学生端
  `InstructionTextRenderer` 完全一致，保证考务预览与考生所见相同；
  分段只决定字体，**不参与任何计分计算**，说明文字永远由结构化配置生成，不从预览文字反推配置。
- **来源**：预览会明确说明这一份是什么：
  - 没有未保存的设置更改时，回显**服务器保存的说明**（学生端当前显示的那一份）；
  - 有未保存的更改时，显示**当前填写内容的预览**，并说明它与服务器上的说明是否相同；
  - 新建考试或服务器没有返回说明时，明确说明「保存后由服务器生成」，不冒充学生端当前显示的内容。
- 判定「未保存的更改」按设置指纹（名称与科目题组）；只改考试时间不算修改设置，不会误报。

## 边界与衔接

- `AdminApiClient.GetExamDetailAsync` 在**返回前**校验考试身份、科目题组与考生说明完整
  （说明缺失或含空行即整体拒绝 `INVALID_RESPONSE`），否则页面会把「缺少说明」误显示成「尚未保存」。
- 切换考试、更换服务器与开始新建考试都会清空已缓存的服务器说明与预览，不会把上一场考试的说明带到下一场。

命令与结果见对应 PR 的「开发期模块验证」；本文件不复制运行日志。
预览字体由界面绑定冒烟用例断言（渲染出的分段中同时存在黑体与 Times New Roman），
分段与来源选择由单元用例覆盖。
