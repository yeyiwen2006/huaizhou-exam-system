# C04：需求界面修复补充

2026-10-06；基线为 main `d517f8a`。关联 C04 / #46、界面审查 R1–R4、R6；交 A 审查，未自行合并。

上游 PR122 已接入权威监控快照、持续刷新、业务/连接状态、按人和试场筛选、指令重发、请求补传与设备冲突选择。本分支保留该实现，撤除早期重复接口和迁移，只补充下列需求细节：

- 冲突两台设备分别展示最后通信与最后保存答案时间，以及已保存题数；保存依据只来自当前参试进入版本、对应设备的持久进度。另一台设备没有对应记录时明确显示无保存记录，不用心跳或答案版本推算。现有存储只保留当前进度，本界面不宣称提供被替换设备的历史答案。
- 冲突对照与重发操作上下排列，时间列留足宽度，小窗口可横向滚动；避免在半宽区域裁切两台设备信息。
- 当前答案使用已发布题号；非字母选项标识映射为发布顺序的“第 N 个选项”，缺少对应关系显示待核对。程序仍传递原始标识，不改变答案内容。
- 答案存储版本及成绩页计分规则版本移入默认折叠的“排查详情”。

契约为新增可选 JSON 字段 `ConflictDevice.LastSyncedAt`、`SavedAnswerCount`、`MonitoringParticipant.CurrentOptionIds`；没有数据库迁移。旧响应缺少保存记录时明确显示无记录，不能推断保存成功。新增查询限制冲突设备的 presence 必须属于同一考试、对应学生会话，进度必须属于当前进入版本。
