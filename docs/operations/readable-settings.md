# 题组编辑与考试名称

考务端的题组列表可直接编辑名称、题型、顺序、题量和满分；编辑时行的位置保持不变。选中题组后，在下方设置是否允许不作答及计分规则。单项选择题显示一个正确答案的计分规则，多项选择题显示多个正确答案的计分规则，不定项选择题显示两种规则。切换题型暂时隐藏的输入不会被清空；保存时，服务器按当前题型校验规则。

GUI 和 CLI 都按唯一的考试名称选择考试，不另设考试类别。名称去除首尾空白后不区分大小写，并遵守 Windows 文件名限制。内部考试标识不随更名变化，已有参试记录、答卷和成绩仍关联同一场考试。

考试名称、科目与考试说明由考试设置和正式发布流程写入，不提供独立改写学生展示内容的接口。考试说明由结构化规则生成，考务端可以预览。历史数据格式和数据库列保留兼容，但旧类别不再作为学生界面的业务字段。

开考后不能改变试卷结构。修改时间的原因可选填；服务器核对当前版本，并记录操作者、调整前后的时间及已填写的原因。存在已确认参试但尚未回收的答卷时，考试不能隐藏。

“全部考试”的每张卡片提供“在学生端显示”勾选框，修改后直接同步服务器，无需保存考试设置。试卷导入期间可切换同一考试的其他功能页面，顶部提供返回导入进度的入口；导入结果保留在原考试中。
