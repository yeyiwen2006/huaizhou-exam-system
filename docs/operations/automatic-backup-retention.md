# 自动备份、恢复归档与磁盘告警

自动维护由管理宿主执行。创建新备份和清理旧材料分别判断，备机离线不再直接阻止主库创建新备份。管理宿主启动后约 30 秒开始检查，此后每 5 分钟检查一次；新备份默认每 24 小时创建一次。

## 创建与重试

创建前核对当前主库身份、目录边界、正在运行的原生备份以及磁盘余量。预计新备份大小按最近自动备份的 1.25 倍估算；首次运行采用数据库目录大小估算。创建期间每分钟重新检查可用空间，低于安全余量会取消本次新备份，但仍单独评估安全清理。

备份只有通过完整的 `pg_verifybackup` 校验及资源、受保护配置的清单校验后，才写入 `maintenance-complete.json`。不能仅凭目录存在、原生工具退出成功或文件名判断有效。恢复仍应定期在隔离环境中实际演练，文件校验不替代恢复演练。

重启后，有完整备份清单但缺少完成标记的请求会重新校验并补全标记。能证明属于本程序当前请求和当前数据库、没有备份或恢复读取者占用的半成品，可在重试前回收。旧版本遗留且无法证明归属的半成品原样保留，并解除其对后续新备份的永久阻塞。程序不会批量删除所有缺少清单的目录。

每个 24 小时重试窗口默认最多尝试 3 次，失败后至少间隔 1 小时；下一窗口自动恢复尝试。重试等待期间，磁盘检查和清理评估继续运行。

## 保留边界

默认保留最近 7 天的恢复窗口、窗口之前最近的一份锚点备份，并至少保留最近两份有效备份。只回收满足条件的自动备份；手动备份和启动校验固定引用的备份目录不会作为自动旧备份删除。

WAL 清理依据备份的原生起止位置、当前时间线历史和复制保留位置，而不是文件修改时间。跨时间线时沿祖先链分别证明所需区间；分叉处只接受完整 WAL 文件提供祖先前缀，不把 `.partial` 当成完整段。时间线历史文件、未知分支和无法证明过期的材料均保留。

清理前校验保留备份，核对所需归档文件的连续性与长度，重新检查主库身份和复制位置，并取得备份目录独占租约。内置备份、恢复读取操作持有共享租约，避免恢复正在读取时删掉它的来源。关键历史缺失、归档缺段、清单损坏、集群身份不符或存在隔离恢复工作材料时，只暂停未获安全证明的清理，不用这些条件直接禁止新备份。

备机长期离线仍可能要求保留大量 WAL。归档目录与 `pg_wal` 是两处不同的占用，复制槽可能约束后者。自动维护不会删除或推进复制槽，不会关闭归档，也不会为了容量上限破坏恢复链。空间告警持续时，应接回备机、增加空间，或由负责人明确安排备机重建；不能同时承诺无限期保留离线备机的任意旧恢复位置和固定磁盘占用。

## 考务端提示

考务端使用已登录的业务身份，只读查询管理状态。即使没有打开服务器管理页面，也会约每分钟读取一次。出现空间不足、复制积压、备份失败、清理受阻或状态失联时，顶部显示提示；管理页还显示备份、恢复归档、`pg_wal` 和复制保留量、最近成功备份时间。

状态超过 15 分钟未更新、格式损坏或来自旧版管理宿主时，不显示为健康。此功能依赖考务端运行且业务会话有效；它不是短信、邮件或关机后的系统级告警。

配置项位于 `Backup:Automatic`：

| 配置项 | 默认值 | 含义 |
| --- | --- | --- |
| `Enabled` | `false` | 是否启用此节点的自动维护 |
| `RetentionDays` | `7` | 连续恢复保留窗口 |
| `IntervalHours` | `24` | 正常备份周期 |
| `MinimumFreeBytes` | `10737418240` | 10 GiB 安全余量 |
| `MaximumAttemptsPerDay` | `3` | 一个重试窗口的最多尝试次数，允许 1～8 |
| `ArchiveWarningBytes` | `10737418240` | 恢复归档容量告警阈值 |
| `BackupWarningBytes` | `21474836480` | 备份目录容量告警阈值 |
| `WalWarningBytes` | `8589934592` | `pg_wal` 或复制保留量告警阈值 |
| `StateDirectory` | 必填 | 与数据库、备份和归档目录互不包含的受保护维护状态目录 |

容量阈值用于告警，不是强制删除所需恢复材料的授权。部署更新只替换程序与运行时文件；保留原连接配置、证书、资源、考试数据库、名单、备份和归档目录。
