# F04 本机服务管理接入

整理来源：任务23策划案、接口与验收矩阵、AGENTS.md、ADR 0002、现行 F01 管理契约与实现。脱敏声明：示例及测试均为合成数据，不含真实账号、试题、部署配置或凭据。

## 当前交付边界

本次在现有考务端增加独立本机管理页。业务登录页及业务顶栏均可进入；业务连接状态只决定返回后的业务页面，不能把正在使用的管理页切走。管理会话不授予考试、激活、报表或账号页面的业务权限。

已经接通 F01 的独立登录、退出、状态、启停、自检、版本化配置、限定日志、备份、隔离恢复和原操作查询。生产管理通信复用 `LocalManagementClient.cs` 单一源文件；考务端沿用源文件链接方式，不引入数据库运行时依赖。

**F04 整卡仍未完成。** 当前正式管理宿主没有 F02 主备状态、接管、应急、重建与恢复同步路由；现有 `FailoverCoordinator` 的内存状态和完成请求表不能充当生产持久协调器。本次未虚构路由、未把配置勾选当作保护状态，也未用合成平台替代生产接线。主备保护始终显示未核实，提示固定在页顶。公共契约、Server 与 Application 目录的补齐按 AGENTS.md“改动前先确认”规则等待授权。本 PR 保持草稿，不关闭任务23。

## 使用

1. 进入“本机服务管理”，填写部署提供的独立 HTTPS 根地址、预期逻辑服务器和本机节点，再用已启用的考务账号登录。仅允许 localhost 或回环 IP；禁止 HTTP、远程监听、路径、查询、用户信息、重定向和证书绕过。
2. 查询本机状态。进程正在运行、业务就绪和当前代次分别显示。未知代次不会补成 0；空检查不显示通过；关键失败明确标记阻止写入。
3. 启停、自检、保存配置、备份及恢复均需确认。配置按读取版本提交；冲突保留表单，明确重新载入并重新确认后才能保存。后端继续核对服务停止、目录、权限和版本条件，不由 GUI 自动停机。
4. 备份只在数据库、受保护配置与版本资源三项完整时报告完成。恢复分别展示隔离暂存、恢复核对与业务就绪。缺最新确认保持阻断；只有后端支持的暂存或缺确认阶段才可显式续办原恢复。
5. 响应丢失后查询原请求。未找到不证明未执行；确认后只可按原请求号、原目标、原账号与原内容重试。不能修改原请求的路径或操作再重发。

本机只保存无秘密的管理地址与身份配置。口令框提交后立即清空；令牌只在独立连接对象内存中，退出或对象释放时清除。退出网络失败会明确显示服务端撤销未确认，不伪报已经撤销。

## 请求、取消与恢复

变更先在当前 Windows 用户 DPAPI 下持久保存原请求与内容摘要，成功后才发送。一个节点只有一个未解决请求；独占文件锁与不覆盖的原子移动防止多个考务实例替换请求。记录损坏、写入失败或链接路径均拒绝发送，不删除原记录。记录没有口令、会话、响应体、试题或原始日志。

每个连接有独立会话代次。切页、退出、取消或换连接后，旧响应不得改变当前页面或清除原请求。页面离开会取消等待和读取，保留服务器操作及其请求记录。短读取期限与最长65分钟的变更期限分别设置；原请求轮询最多10次，每次间隔2秒，只有只读查询，不重发变更，也不与其他读取重叠。

终态失败和完成均先核对请求、操作者、节点、操作类型、内容摘要及相应阶段证据。仅确认终态后移除本机待核对记录；暂存及待核对阶段继续保留。续办恢复使用原始序列化内容，表单后来修改不能改变该请求。

日志只展示受保护接口的固定元数据，每类最多50条。没有任意文件浏览、格式化异常、原始消息或堆栈入口；无效列表、阶段、来源或类别拒绝展示。
