# F04 本机服务管理终版

整理来源：任务23策划案、接口与验收矩阵、获授权的 F02 差异清单、AGENTS.md、ADR 0002 和正式管理实现。脱敏声明：文档、测试与截图均使用合成身份和材料，不含现场数据或凭据。

## 交付范围

考务端已接通 F01 独立管理登录、退出、状态、启停、自检、版本化配置、限定日志、备份、隔离恢复和原操作查询，以及 F02 正式状态、手动接管、单机应急、旧节点重建和恢复同步保护。F02 补齐范围获得用户明确授权，随独立 F04 PR 交 A 审计；开发卡关闭仍须 A 审查合并。

业务登录页和业务顶栏均可进入管理页，管理会话不授予业务页面权限。业务断连不会切走管理页；返回保留业务页面及尚未确认的注册结果。保护警示显示在主窗口，返回业务登录、退出管理会话、断线和客户端重启均不会自动解除已知降级警示。

GUI 源文件链接共享 `LocalManagementClient.cs`，没有 SQL、SCM 或备份执行入口。正式持久协调与部署见 [F02 管理契约](f02-high-availability-management.md)。

## 操作流程

1. 进入“本机服务管理”，填写部署提供的独立 HTTPS 回环根地址、逻辑服务器及本机节点，以已启用考务账号登录。禁止 HTTP、远程管理、重定向或证书绕过。
2. 查询状态。进程、业务就绪、代次、主备模式、复制、材料及证书分别显示。未知代次不补成 0；空检查不报告通过；配置勾选不能证明同步保护已生效。
3. 启停、自检、配置、备份和恢复均需确认。配置携带读取版本，冲突保留表单；重新载入、比较并确认后才能形成新请求。后端继续执行停机、权限和路径检查。
4. 备份须证明数据库、受保护配置与版本资源完整。恢复分开显示隔离暂存、核对与业务就绪；缺最新确认继续阻断，只有正式支持的恢复阶段允许显式续办原请求。
5. 主备变更先查询最新状态，填写已配置目标及原因，再确认影响。接管只在存活备用机的本机管理宿主操作，必须明确确认旧主断电或业务网络隔离；不可达和心跳超时不足以接管。
6. 单机应急先停止业务再切换受保护部署，完成后自检并启动业务，持续显示保护降低。旧节点在其本机执行重建，确认替换旧数据并保留隔离副本，禁止回灌旧库。完成重建后，在活动主节点核对备用节点并恢复同步保护；应急后已恢复并追平的原备用也可直接核对恢复保护，无须强制破坏性重建。
7. 接管提升后本机业务保持停止，按自检及 F01“启动服务”流程启动，使业务宿主读取新代次和确认目录。重建启动非活动节点确认监听，业务写入仍由原门禁拒绝。
8. 响应丢失、取消等待或重启后查询原请求。未找到不证明未执行；仅在明确确认后按原号、原账号、原节点和原内容重试。主备查询不会自动再次提升或再次破坏性重建。

配置没有秘密；口令提交后清空，令牌只在独立连接内存中，退出或释放清除。退出网络失败明确显示服务端撤销未确认。

## 持久请求与警示

变更发送前，在当前 Windows 用户 DPAPI 下保存原请求、目标、已认证操作者和内容摘要。一个节点只保留一个未解决请求；独占锁和原子移动防止其他考务实例覆盖。损坏、写入失败或链接路径阻止发送，不删除待核对记录。记录不包含口令、会话、响应体、试题或原始日志。

短读取和最长 65 分钟变更分别设定期限。离开页面停止读取与等待，保留原请求；旧连接响应不能改变当前页面。原请求轮询最多 10 次，每次间隔 2 秒，只查询、不重发、不重叠。确认终态前核对请求、目标、操作者、类型、摘要和阶段证据。

主备状态超过 10 秒或缺证据时显示未核实，禁止新的主备变更。解除警示须有当前状态、实际复制、材料、证书和双侧最新持久确认，零延迟不能替代。每个目标的降级警示另用 DPAPI 保存；记录损坏保留警示。日志只展示固定元数据，每类最多 50 条，无任意文件或原始消息入口。

已显示的保护证据也会按时失效，不依赖下一次网络响应。重新登录或重启后，低于已保存代次、版本或同版本核实时间的响应不能解除应急警示。检查名称、日志来源/级别和隔离确认采用中文，时间按 UTC+8 显示。

## 回退与整体阶段

本 PR 不新增数据库迁移或评分语义，沿用既有 F02 状态表和业务写入门禁，补充受保护部署选择及明确人工应急授权核对。生产节点和受控数据库服务须预先部署，详见 F02 文档。

回退界面前保留加密原请求、警示和服务端日志。已提升或重建后不能靠代码回退撤销角色，禁止自动切回或合并旧库；由 A 根据实际持久代次及隔离证据决定恢复。真实双机、网络隔离、断电、RTO、现场 SCM/证书及容量由 T02 验收，最终包固定归 T03。
