## C05 原子发布边界

目前 `PostgresVersionedResourceStore.SaveAsync`、`PostgresExamVersioningService.PublishPaper`、`PublishGradingRules` 是分开的写入/发布操作。单个版本操作有自己的数据库事务，但不能据此推断“加密题包 + 试卷版本 + 答案规则”整体原子。C 侧不能通过依次调用再补偿删除来假装安全发布。最小外部需求是 A 在正式服务端提供一个授权、幂等、带版本检查、统一事务或等价可证明原子性的发布能力，并返回可核验的最终版本。C 随后再接 GUI 确认、失败状态清理、目录/ZIP 校验编译、最终状态展示与合成包回归。此能力到位前，不开放会造成半发布风险的正式按钮。
