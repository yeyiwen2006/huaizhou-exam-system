# 选项定位与显示契约

选项通过隐藏外观链接绑定题目和选项标识。提取器校验 PDF 区域后生成与试题同版的坐标文件，学生端在原标签处叠加圆形控件。不得从选项内容猜测答案或放宽缺失区域校验。

### 4.1 标记定义（材料样式提供）

```latex
% \optmark{题目标识}{选项标识}{选项标签文本}
% 第三参数只包选项字母及原有标点，如 A. 或 （A），不得包正文、表格或图片。
% 在标签外建立隐藏外观链接，目标名固定为 opt:<题目标识>:<选项标识>。
% 不改变外观与占位；目标名只含题目与选项标识，不含答案、分值等任何计分信息。
\DeclareRobustCommand{\optmark}[3]{\hypertarget{opt:#1:#2}{}\hyperlink{opt:#1:#2}{#3}}
```

标签文本作为第 3 参数进入链接，使链接矩形落在选项字母上。标签无法由选项标识推出，
同一份材料中可以并存 `A.` 与 `（A）`，因此显式传入。样式加载 hyperref 后设置 `\hypersetup{hidelinks}`。
每个选项只调用一次宏，标签保持单行。正文可多行、含图或表格，不改变标签矩形的范围。
`hidelinks` 隐藏链接外观，仍保留 Link 注解；不得设置使注解本身不可用的隐藏标志。

### 4.2 抽取规则

- 使用 `page.GetAnnotations()` 筛选 Link 注解，从原始动作字典的 `/A /D` 或直接目标 `/Dest` 读取目标名。
  `Annotation.Name` 对应 `/NM`，不能充当目标名；不得依赖只提取外部链接的 `GetHyperlinks()`。
- 标记必须解析为同一 PDF 内的 GoTo 目标，且目标页与注解页一致；远程目标、其他动作或无法解析的目标失败。
- 只处理 `opt:` 命名空间。普通链接不计入选项数；`opt:` 标记格式错误、悬空或指向其他题目时失败。
- 按清单生成完整的预期目标名，以大小写敏感的精确比较绑定 `(questionId, optionId)`。
  现有 schema 不限制标识内的冒号，不能直接按冒号拆成固定三段；若两组标识产生相同目标名，报告冲突并拒绝发布。
- 每个清单选项必须恰好对应一个标签区域。通常每项只有一条注解；确有碎片时，仅允许同页且相互重叠或相接、
  连通的碎片取矩形并集。同名但分离的标签按重复标记失败，同名跨页也失败，禁止跨页取并集。
- 选项缺失区域、清单外标记、重复或无效区域均使整次抽取失败，不产出部分文件。错误包含题目标识、选项标识和所在页。
- 最终结果按清单选项顺序输出，仍按标识查找并核对 `options[i]`，不得按注解遍历顺序或坐标排序绑定答案。

### 4.3 归一化定义（`anchorScheme = pageTopLeftNormalizedV1`）

- `pageIndex` 固定**从 0 开始，相对于该题 `PdfPath` 指向的逐题 PDF**。第一页为 0，第二页为 1。
  PdfPig 的 `page.Number` 从 1 开始，写产物时减 1；Windows.Data.Pdf 的 `GetPage(pageIndex)` 直接使用该值。
- 标记校验的几何输入统一取 `AnnotationDictionary` 中尚未变换的原始 `/Rect`。四个数先取横纵 min/max，再构造四角。
  **不得将 `Annotation.Rectangle` 当作原始 `/Rect` 再裁剪、旋转**。PdfPig 0.1.16 已对该属性应用初始矩阵。
- 有效显示框取该页 CropBox 与 MediaBox 的交集，缺少 CropBox 时使用 MediaBox；继承的页框和 Rotate 也须解析。
  页框宽高必须为正。原始坐标和页框使用同一单位，不混用 TeX pt、像素或已缩放的尺寸。
- 设有效显示框左下角为 `(cx, cy)`、宽高为 `(cw, ch)`。对每个原始角点 `(px, py)`，先算
  `u = (px - cx) / cw`、`v = (py - cy) / ch`，再按 PDF 顺时针 Rotate 转成左上角归一化坐标。

| Rotate | 角点的 `(X, Y)` |
| --- | --- |
| 0 | `(u, 1 - v)` |
| 90 | `(v, u)` |
| 180 | `(1 - u, v)` |
| 270 | `(1 - v, 1 - u)` |

四角变换后取 `x = min(X)`、`y = min(Y)`、`width = max(X) - x`、`height = max(Y) - y`。
所有数必须有限，宽高为正，且 `x >= 0`、`y >= 0`、`x + width <= 1`、`y + height <= 1`。
有效框外的标签失败，不通过裁掉标签或钳位到边界隐藏异常。页索引须小于该题 PDF 实际页数。

原始链接校验及同名碎片合并完成后，在该标签范围内查找可见的字母/数字字形，
取它们的边界并集作为最终显示区域。`A.` 的句点、`（A）` 的括号及链接留白不参与圆心计算；
只接受完整处于标记范围内的字形，忽略不绘制的隐藏文字，不搜索标签外的选项正文。
标签文字与 `optionId` 可以不同，题目及选项的归属始终取链接目标，不能从字母推断标识。

PdfPig 0.1.16 的 `Letter.BoundingBox` 已应用该库的页面裁剪平移与旋转。
须先按该库实际使用的 `Page.CropBox` 和旋转逆变换四角，恢复原始 PDF 坐标，
再按本模块完整解析的有效显示框归一化。库的页框可能遗漏继承信息，不能直接与契约页框混用；
也不能把已变换字形当作原始坐标再次旋转。
标签为图片、路径或字形不可读，且范围内无可用文字字形时，保留校验后的原链接区域，
不猜测字母位置。这类标签仍须在导入预览中核对，不能声称已精确对准字形。

以实际显示的 PDF 页面图像左上角为原点，按该图像宽高缩放最终矩形，圆心取矩形中心。
`overlay.text` 保存抽取的字母/数字，`overlay` 的矩形保存标签内可见字母与标点的边界并集，不含链接留白。
以字形中心到遮盖矩形最远角的距离确定圆半径，只额外保留 0.5 DIP 抗锯齿余量，
不另设最小圆径。按钮内用白色 Arial 字母重新显示标签，禁用时仍保持不透明。
无可读字形或旧包没有 `overlay` 时，以已有区域作为遮盖范围，并从清单 `optionCaptions`
（省略时用选项标识）去除标点后显示；这类包不保证字形精确居中，须重新抽取或预览核对。
控件容器的留白、滚动偏移和 DPI 变换须另行计入，不改写坐标产物。
PDF 先按原始尺寸建立布局（1 PDF 点 = 96/72 DIP），再将题目及按钮整体固定放大到 125%，
不随窗口宽度变化，不提供手动缩放。上下按实际内容裁切并各留 18 个原始布局 DIP；
左右先固定对称裁去原页面的 20 毫米空白，再整体放大。
若任一页的内容进入左右裁边区，整道题保留原页宽，避免截断内容。

真实试卷、实际设备 DPI 和点击位置按验收标准逐题核对。

### 4.4 产物形态

选项定位区域**不写入源侧导入清单**，符合 [逐题显示元数据 schema](../schemas/display-metadata.schema.json)。
学生包中固定为根目录 `option-regions.json`，与 `manifest.json` 和逐题 PDF 放在**同一加密 ZIP** 内，
按 `(examId, paperVersion)` 一起生成、下载、校验和切换，不设学生端明文坐标下载入口。

新产物 `artifactVersion` 为 2，读取器兼容旧版 1，`anchorScheme` 仍为 `pageTopLeftNormalizedV1`。
v2 新增可选 `overlay` 对象，字段为 `text/x/y/width/height`；矩形遵循相同归一化和边界校验。
v1 不允许携带非空 `overlay`；字段类型、缺失、未知字段、重复 JSON 字段及非法遮盖范围须整包拒绝。
考试及试卷版本必须与学生清单一致。每个清单题目及选项恰好出现一次，PDF 路径沿用学生清单的题目映射。
下面是只有 A、B 两个选项的合成题示例，第一页用 0 表示。页面为 200×100 PDF 单位，
14 单位字号的 Helvetica 标签 `A.`、`B.` 分别从基线坐标 (30,30)、(30,60) 绘制；
字形矩形不含句点及链接留白；原链接分别为 (25,25)-(50,50)、(25,55)-(50,80)，
链接内可见字母及句点的边界并集记录到 `overlay` 供实心圆遮盖。未使用真实题目。

```json
{
  "artifactVersion": 2,
  "anchorScheme": "pageTopLeftNormalizedV1",
  "examId": "synthetic-contract",
  "paperVersion": 3,
  "questions": [
    {
      "questionId": "q-001",
      "options": [
        { "optionId": "A", "pageIndex": 0, "x": 0.15098, "y": 0.59948, "width": 0.0448, "height": 0.10052,
          "overlay": { "text": "A", "x": 0.15098, "y": 0.59948, "width": 0.05908, "height": 0.10052 } },
        { "optionId": "B", "pageIndex": 0, "x": 0.15518, "y": 0.29948, "width": 0.03871, "height": 0.10052,
          "overlay": { "text": "B", "x": 0.15518, "y": 0.29948, "width": 0.05488, "height": 0.10052 } }
      ]
    }
  ]
}
```

旧包仍可读取，但坐标和遮盖信息不会自动补全。需先升级学生端，再重新抽取、生成并按新的
`paperVersion` 发布 v2 题包，已有试卷才获得字母居中和按完整标签遮盖的效果。
旧学生端不支持 v2，不能把新包发布给未升级的学生端。
不得只替换已发布包里的坐标文件，PDF 与坐标继续按同一试卷版本原子切换。

## 版本与依赖

坐标产物、学生清单、PDF 和加密题包共同校验版本。坐标不是普通显示附件，不能通过放宽 ZIP 未知文件规则接纳。旧包保持原义，缺少有效坐标时不猜测点击位置。升级学生端后重新生成、预览并发布新版本，不原地修改旧密文。

PdfPig 版本由依赖锁固定。升级时重新验证原始注解、继承页框、裁剪、旋转和可见字形语义。真实编译检查使用 `latex` 分类，导入全流程使用 `import-e2e` 分类。
