# 验收标准

本文件保留系统需求对应的功能、故障和性能门槛。代码检查、单机合成测试和现场验收分别记录，不相互替代。

## 可靠性与发布

| 范围 | 实施要求 |
| --- | --- |
| 学生端持久化 | 答案、版本、待提交快照事务保存；本地写入失败进入明确故障状态，保留内存待保存内容、最后可靠版本并暂停新修改。恢复写入后先保存并核对，再允许继续；不能清缓存后重试 |
| 服务器存储 | 事务失败回滚并返回错误，保留原交卷重试依据；数据库不可读、空间不足或写入异常时暴露故障，不能返回成功、覆盖原库或静默重建。健康状态以实际持久化能力判断 |
| 启动与重连 | 启动先检查存储及所需资源，再恢复考试状态、有效时间和待处理事件；未就绪时管理页可查看原因，业务入口明确返回恢复中。客户端按身份与各版本重连，不凭本机时钟或旧缓存回退终态 |
| 资源与长任务 | 编译、下载、备份及导出使用独立任务、超时和资源上限；半成品不替换当前资源，失败保留完整旧版。重试并发、队列长度及日志空间有上限，持久待发任务不得因重试次数被删除，关键任务不能被下载导出长期阻塞 |
| 备份与恢复 | 使用一致数据库快照，连同对应题包、规则、事件、身份及密钥恢复材料形成完整备份。恢复到隔离位置核对，保留故障原件；不能用旧备份覆盖更新答卷。无法证明状态完整时报告缺失，禁止自动恢复收卷或出表 |
| 发布与现场状态检测 | 发布时固定通过验收的程序和配置版本；GUI/CLI提供写入、空间、连接、版本、题包及密钥可用性检查。考前检查结果明确列出阻止使用的故障；考试期间禁止自动升级程序或迁移数据库 |

恢复优先保护答卷、身份和有效版本，不通过重置数据库或重新创建考试掩盖错误。故障造成的停顿、服务重新可用时间和客户端恢复时间分别记录；“服务可用后10秒恢复”不包含主机启动、人工隔离或备份恢复耗时。

## 功能与故障场景

用隔离测试时钟或短场考试控制时序，不修改正式服务器系统时间。

| 场景 | 操作与检查 | 必须得到的结果 |
| --- | --- | --- |
| S01 连接、编号与试场 | 首次填写地址，后续启动恢复可信活动节点；默认 HTTPS 443，完整 HTTPS 根地址可指定端口，无需设备激活批准直接登录；当天重复登录、跨日登录、并发分配、重启及 9999 上限；创建改名分组、单个批量转组、删除空组和非空组 | 登录页位于独立考试桌面，仍可移动、缩放和关闭，不显示独立端口框；取得 YYYYMMDDXXXX 编号，当天沿用、次日重分、同日无重号、重启接续；考务可查看学生端信息，转组不改考生和成绩，非空组不能删除 |
| S02 名册与参试 | 三列名册添加、导入、补充，测缺项、错表头、非数字、完全重复及冲突；四人中一人只登录、一人仅下载、两人确认等待，再退出一人 | 错误逐行定位且不部分导入，前导零保留，身份不符拒绝；实际人数依次0、2、1，重复退出不再减人；退出取消或失败不移除。另测开考前20分钟、结束边界、缺包及退出与开考竞争 |
| S03 选项与标记 | 单选替换及取消；多项、不定项依次选A、C、不作答，再取消；标记后重启、切换账号再切回 | 分别得到A、AC、abstain、empty，前三项题号绿，最后恢复未答；不作答与普通选项互斥，私人标记恢复且不串号、不上报 |
| S04 交卷与回执 | 在固定本地答卷、服务器事务、发送回执前后分别注入故障；丢成功响应后重发20次，再换提交标识、重放旧进度 | 恢复固定快照，仅一份最终答卷；已保存时返回原回执、不覆盖或重复计分；成功回执均有持久答卷，再次进入被拒绝 |
| S05 多端裁决 | 甲作答时乙申请，考务保留甲或改选乙；重放甲旧进度与提交，再测裁决和提交并发 | 乙裁决前不能答题，原端不自动失权；一条参试记录，旧授权不能写有效数据，换机仅恢复服务器已保存进度，已交卷不能重考 |
| S06 时间与可靠通知 | 改学生机时钟，丢失、重复、乱序通知，断网及服务重启跨结束时间；计划结束后、收到END前改答，再补发END并重试 | 时钟不改变考试状态；首次提交前最后选择有效，固定后仅重发原快照；恢复最新状态，旧指令不回退，确认与收卷分别计数 |
| S07 加密与本地恢复 | 等待时读取缓存、索要密钥；开始后解锁，答题后结束进程并恢复；替换错误密钥或损坏包 | 开考前只有密文和无题目内容的说明，提前取钥拒绝；解锁恢复答案和标记，错误密钥及损坏包不显示，日志无明文密钥 |
| S08 内容修订 | v1选A后发布v2，修改题干图片及选项文字；先下载失败再重试，重复通知；另有一人已提交v1 | 失败保留可恢复旧版；完整更新后选择和标记保留、提示复核；监测区分收到、下载及复核状态；结构增删拒绝，旧版有效答卷仍收，已提交不恢复 |
| S09 时间修订 | 开考前提前开始时间，开考后后移开始时间；延长结束时间越过旧截止，再改到当前之前，结束后再延长；通知丢失、旧结束指令晚到及离线重连 | 到期立即开始或结束，旧任务失效；已开始不退回等待；结束后延长至当前之后重新开放并可靠推送学生端，允许符合条件的新参试；旧结束指令不关闭新窗口，已提交或本机已固定答卷不恢复作答，历史更正重放不自动重开 |
| S10 监测与回收 | 查看所有业务和连接状态；当前人员提前交齐后新增一位合法参试者，结束时缺其答卷，再补收；另测零参试者 | 编号、试场、账号、进度对应正确，离线不等于未参加；名单各版本最多提示一次，零人不提示；提前全收或结束缺卷均无表，补齐后统一出表，不自动计零或移出 |
| S11 规则重算 | 四人合成样例中修改答案使1002科目甲由0变正，再反向修改；扩展场景另有一位已实际参试者并发补交 | 全部答卷用最新版，仅甲科及甲科小题样本随甲科成绩变化；其他单科样本不变；总分仍按所有科目非零筛选。班级使用相同口径，表格整体切换，原始答案不变；扩展场景另列预期人数与均值，不在结束后新增参试 |
| S12 GUI与CLI | 依完整覆盖清单用两种入口执行全部考务及服务器功能，包括权限错误、长任务、裁决、补发、事件订阅和导出 | 输入校验、权限、结果和错误对应，CLI可独立完成业务；GUI有回收弹窗，CLI有冲突、回收及失败通知 |
| S13 不同试卷结构 | 导入至少两份不同名称、科目、题组顺序、题型组合、题号、题量、选项数量与分值的合成包 | 同一程序无需改源码或重编译即可显示、导航、判分及导出；审查无真实试卷常量或按校名、考试名、文件名分支 |
| S14 导入与原版显示 | 本地导入三校完整材料，逐题比对字体公式、图片表格及选项；检查多页、滚动、缩放，完整导入包换目录后重复导入；输入缺依赖、重复题号、错误选项、非法路径和编译失败包 | 版式与控件对应原文，无固定移图或改对齐，整包移动不影响图片引用；错误定位且阻止发布，学生包含题图而不含答案解析、专用资源或泄密元数据 |
| S15 分数与报表 | 覆盖三种题型、两组规则示例、部分选对、错选、空选及不作答；验证0.1+0.2、最终1÷3、负小题、四人样例、空样本与精确均分同显值 | 0.1+0.2精确为0.3，最终无限小数规则拒绝；-1与0.25先相加后单科归0且不抵扣其他科；各科独立非零样本、总分全科非零样本、班级对应样本及空样本排名正确；五类列项颜色、固定平均行、前导零及长精确成绩符合需求 |
| S16 Windows与发布恢复 | 普通账户运行发布包，实测独立桌面、触控板三指/四指手势、任务视图、多显示器、输入法、全屏及快捷键、切出补报、退出和异常结束恢复、锁屏再解锁、全页编号姓名和换账号；全新部署并备份恢复，服务器停止后由CLI或服务器运维工具启动 | 无需SDK、TeX或管理员预配；不能借任务视图进入原桌面应用；不虚称阻断系统安全界面和强制结束，账号数据不串；考务登录后直接进入服务器管理，退出或换账号不保留旧管理权限；GUI不提供业务启停，编号、资源解密、答卷及事件可恢复，继续完成考试 |
| S17 GUI风格一致 | 并排核对学生端、考务端及其服务管理页面，在100%、125%、150%缩放下比较共享控件；从共享主题修改一项样式并检查各端 | 同类按钮、表单、表格、弹窗、状态提示的颜色字号间距与交互一致，无独立复制主题；编号姓名、操作和文本可达；试题自身字体排版不被主题改写 |
| S18 存储与资源故障 | 在隔离测试环境模拟学生端及服务器磁盘写满、不可写、数据库不可读、下载或备份中断；对照故障前已确认状态 | 不返回虚假成功，不清空原数据，不以半份包替换旧版；学生端保存失败明确提示并暂停新修改，服务器失败保留待提交重试；修复后恢复可靠版本并继续收卷 |
| S19 主机重启与现场恢复 | 用合成考试在隔离虚拟机做强制断电与重启演练；另测资源或密钥缺失、旧备份恢复、程序重启期间集中重连，按恢复说明实际完成剩余考试 | 已确认持久数据可恢复，启动检查阻止带关键缺失上线；旧状态不覆盖新记录，不重复开考计分；记录故障至服务可用和客户端恢复耗时，全部剩余答卷可回收。不能仅以结束进程代替断电演练 |
| S20 原主失效与接管 | 双节点保护正常时混合答题交卷，使原主不可用；备机登录页直接进入服务器管理，先实际隔离旧主再点击接管；随后修订、收齐、重算及导出 | 只允许本机已核实备库接管；无需访问旧主磁盘。代次递增，新主自动启动并通过就绪检查；双机已确认数据保持，未决请求沿原身份、答案和提交标识补传，只一份最终答卷；心跳丢失和未确认隔离均不能切主 |
| S21 备机故障与原主回归 | 单独停止备机，或切断节点间网络但保留学生连接，继续保存交卷、查询回执并恢复备机；另测接管后旧主带旧数据回归 | 健康主机自动按本机持久化返回成功，清楚显示单节点运行，无应急按钮；本机落盘失败仍拒绝虚假成功。普通备机自动追平；旧主保持隔离并重建为备机，不覆盖新主、不双写；数据库、资源和最新独立确认全部追平后显示双节点保护正常 |

## 性能与部署

参考环境为 Windows x64，两台服务器各至少8个逻辑处理器、16GB内存、独立SSD和千兆有线接入。客户端覆盖普通账户、1366×768及以上分辨率、100%、125%、150%显示缩放，以及实际使用的 Windows 10/11版本。报告记录系统、硬件、可用带宽、试卷包大小和真实设备数量。

性能分别验证双节点复制正常和仅一个健康节点两种状态，不能用一种状态的结果代替另一种。请求采用完整业务数据，至少覆盖复旦 120 题的答题状态与三类样卷中最大的实际编译包。模拟负载从独立机器经局域网访问服务器，不能只使用服务器本机回环地址。百分位按每类请求分别统计，P95 表示 95% 的请求耗时不超过该数值。

| 场景 | 负载与检查 | 通过标准 |
| --- | --- | --- |
| 300 人正常考试 | 300 个独立账号和会话，60 秒错峰校时；每人平均每 2 秒一个合成答题或切题事件，同时打开考务监测 | 持续至首批最长考试的完整时长；正常业务零最终失败，状态接口 P95 不超过 500 毫秒、P99 不超过 1 秒；无未解释的持续内存增长 |
| 300 请求集中到达 | 300 个实际校时与完整状态同步请求集中到达，响应须包含已持久保存的状态版本 | P95 不超过 500 毫秒、P99 不超过 1 秒，单次不超过 2 秒；零数据错误，不能用纯时间接口代替 |
| 集中下载 | 300 个客户端获取含图片的最大实际试题包，完整校验文件与说明齐备，同时维持监测和指令 | 全部下载在 120 秒内完成；无永久失败；控制和交卷流量保持下述时限。实际包过大或网络不足时须优化或记录未达标，不能缩小样卷掩盖问题 |
| 开始与结束 | 300 会话接收服务器立即发出的指令，正常网络下测量从计划触发到客户端处理的时间 | 全部在 3 秒内处理，P95 不超过 2 秒；重复处理不产生重复业务 |
| 集中交卷 | 300 份完整答卷同时提交，计入持久化与回执到达时间 | P95 不超过 3 秒，全部在 10 秒内确认；最终答卷数与实际参试人数一致，无重复计分 |
| 即时监测 | 登录、等待退出、答题、提交、设备裁决与切出事件 | 正常联网时 GUI 和 CLI 状态更新不超过 2 秒；无通信超过 135 秒标为离线，明确断开立即标记 |
| 丢指令与恢复 | 漏收一次通知、断网后重连、服务器重启后恢复；仅在网络和服务已恢复可用后计时 | 在线单次漏收通过重发在 10 秒内补齐，重连后 10 秒内取得正确状态并继续原交卷任务；保留答卷和事件，旧指令不回退状态 |
| 全部回收与结果 | 最后一份实际答卷持久保存，及考试结束与回收条件同时满足 | 回收完成通知在 2 秒内出现；300 人三类样卷的统计结果在两项条件满足后 10 秒内可用；任何未完成条件下均不能取得表格 |
| 考试中发布更新 | 300 会话接收时间调整与题包更新，包含仍使用旧版本的设备 | 时间通知及监测更新不超过 2 秒，新题包按集中下载 120 秒指标验收；失败可重试，已交卷不重新开放；结束后延长的重新开放按 S09 验证 |
| 主备接管 | 300会话答题与交卷中使原主不可用，确认隔离后发起接管 | 故障前双机已确认数据损失0；发起接管后60秒内新主可用，客户端在服务可用后10秒内恢复；人工发现及隔离耗时另记，原主回归不双写 |
| GUI 与服务并行 | 正在下载、监测或生成 Excel 时执行校时和交卷 | 同样满足对应接口时限，界面和导出任务不能阻塞通知及交卷保存 |

故障注入阶段单独记录暂时失败和重试，不能用无故障阶段的零失败要求掩盖必要的重试。判断标准是恢复后得到正确状态、原回执和唯一答卷，已完成双机确认的数据完整保留；单份期间按已接受的边界核对幸存节点实际保存的数据，不能虚称缺失的另一份已经恢复。计分修改后的全量重算也以 300 人样卷为基准，目标 10 秒内完成并整体发布，期间旧表格不可用。

300 个模拟会话证明服务端在相应负载下的表现，不能代替 300 台真实设备与无线网络的验证。正式场地安排实际设备演练，报告分别列出模拟和真实设备规模；没有测过的网络条件不写成已经验收通过。

## 校时与负载诊断

300人每60秒一次平均约5次/秒，集中启动仍有突发。若每次上传10kB，300次合计3MB即24Mb，空闲100Mb/s链路仅传这些载荷理论约需0.24秒，千兆约0.024秒，平均约占0.4Mb/s。估算不含响应、协议、握手、无线竞争、重传及处理时间，不能当作实测结论。

小请求不必然挤满本机网卡。流量高且重传多时检查网卡、交换机及无线接入；流量低但响应慢时检查写入队列、锁等待、CPU、磁盘和GUI阻塞。大题包下载需与通知、交卷一起测量，不能只测返回时间的空接口。

首次校时立即进行，后续首次间隔在60秒内错开，再各自每60秒执行；重试退避加少量随机延迟，开始结束首次通知按时推送。复用连接，并分别安排下载、通知和持久写入的处理资源。依据见[周期任务与重试说明](https://d1.awsstatic.com/builderslibrary/pdfs/timeouts-retries-and-backoff-with-jitter.pdf)、[RFC 9112连接复用](https://www.rfc-editor.org/rfc/rfc9112.html#section-9.3)。
