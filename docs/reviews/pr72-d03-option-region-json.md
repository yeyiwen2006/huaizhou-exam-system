## 已复现的问题与修复

1. **重复写出改变坐标与文件字节。** `Math.Round(double, 6, ToZero)` 会受二进制乘法精度影响，把已规范化的 `0.000249` 再截成 `0.000248`；`0.000251`、`0.000489` 同样受影响。现在先取 invariant 最短往返十进制表示，再用 decimal 向零舍入；小于精度的正数保留，负零规范成零。已规范化产物再次读写字节不变。
2. **写出前没有验证原始产物。** 原实现可输出无效版本、空集合、重复标识、负页码和越界区域；嵌套 null 会抛空引用异常。尤其 `x=0.999999999, width=0.0000004` 本身越界，却被舍入掩盖。现在写出前校验所有原始字段与集合，读写共用区域范围判断，非法产物以参数异常拒绝，不产生部分返回值。原边界测试改用真正有效的 `x=0.9999996`，保留原断言；新增用例单独钉死旧非法输入必须失败。
3. **非法 Unicode 导致读取异常逃逸。** 合法 JSON 语法中的孤立转义代理项会在 `GetString()` 抛 `InvalidOperationException`，破坏「失败结果而非部分产物」的读取契约。现在先严格检查 UTF-16 到 UTF-8 编码，再将 JSON/非法代理项错误转换为 `RequestInvalid`；写出标识也拒绝非法 Unicode。
