## 已修复的主要问题

### 启动和界面阻塞

真实 WPF 窗口测试及可执行程序启动复现了共享样式的 `AlternatingRowBackground`、`Padding` 资源解析异常；进一步渲染还复现了 `Track.Thumb` 被错误赋为 `Border` 的类型异常。跨字典设计值改为动态资源引用，同字典的样式继承保持静态引用；滑块改为真正的 `Thumb`，并补齐横向尺寸、方向和翻页命令。颜色、字体和间距仍取自原共享设计资源，没有另建页面私有色板。

C01 的题型列改为实际可绑定的 `ComboBox` 模板，避免在不属于可视树的列对象上寻找 Window 祖先。说明文本使用显式单向绑定。新增的 WPF 测试实际启动窗口、切换五个标签页、修改题型，检查设计资源的实际取值、横向滑块及数据绑定错误，不能仅以 XAML 编译成功代替运行验证。

### C01：计划并发更新与字段约束

保存计划不再先读取最新版本后盲目覆盖。新增“加载服务器计划”：更新使用操作者实际加载的 `ScheduleVersion`，未加载时只尝试新建；已有考试、版本冲突均由服务器明确拒绝。成功后才推进已知版本；冲突保留当前草稿，不自动覆盖或重试。切换考试、重连或请求期间修改草稿时，不应用过期的计划加载结果。

补齐跨科目的题组 ID 唯一性、动态新增/删除后的 ID 和排序、不合法及多重扩展名 Windows 保留文件名、schema 字段长度等检查；默认题量、单题分值与满分一致。选择题组后及时更新删除按钮状态。说明明确区分本地字段/字符检查与服务器的表达式语法、求值和满分一致性校验。

### C02：名册导入安全与预览一致性

名册字段仍为姓名、班级、准考证号。导入拒绝公式表头/数据、额外列、多工作表、超限文件/解压体积/行数，以及可能丢失前导零或精度的数字型标识；班级和准考证号必须真正以文本存储，不能仅靠数字显示格式补零。

预检和读取使用同一个只读文件流，避免检查之后换文件。全批校验重复与冲突；任何错误阻止整批确认。任何名册集合变化都会使旧预览失效，防止预览后手工添加或变更名单再导入旧快照。界面明确说明名单仅在当前进程内存中，关闭即丢失，尚未写入服务器。

### C03：激活、查询与本地分组边界

激活结果使用服务器返回的客户端编号，不在 GUI 生成编号。补充房间组草稿重命名并保留组 ID，拒绝重复名称；重连后清除设备结果和审批输入，避免沿用另一服务器的数据。本地房间组始终标为草稿，删除草稿不宣称已经删除服务器分组，也不把查询到的部分设备当成服务器全量成员校验。

### C04：监控、裁决与收齐事件

监控请求使用上下文和请求序号，处理“考试 A → B → A”及同一考试请求乱序；切换考试或服务器会清除旧记录和处置输入。选中记录可带入服务器版本字段，参与业务状态和连接状态分开显示，不用在线与否伪造业务状态。

设备裁决使用服务器授权结果；裁决已成功但随后刷新失败时，明确显示“裁决已保存、刷新失败”，避免诱导重复执行，并保留服务器返回的操作者、原因及授权/撤销设备信息。

接入主线已有的持久化收齐事件 API，提供手动查询、分页游标、去重、列表和统一弹窗。整页验证考试 ID、事件标识和名单版本后才推进游标，拒绝跨考试事件。历史收齐事件不保证当前名单仍已收齐，也不等同于成绩已开放；界面与弹窗均作此区分。

### 连接、身份和失败语义

健康检查是公开接口，不能证明令牌有效；连接检查增加受保护的只读考试查询，并要求官方 `EXAM_NOT_FOUND` 封套，不把代理普通 404 当成认证成功。操作者 ID 的写入审计校验仍由服务器负责，界面不声称 GET 检查已验证该 ID。

远端地址要求 HTTPS，仅本机测试允许 HTTP；禁止地址内嵌用户信息、查询和片段，禁用自动重定向。响应要求有效服务器身份和代次，拒绝外来服务器、旧代次及同代次异节点；重连后不接受旧连接响应。代理 HTML 和无效 JSON 不再伪装成业务成功，也不把响应正文输出为错误详情。

同一连接内，相同写操作在丢响应或暂时失败后复用请求 ID；只有确定成功或官方非重试性拒绝才结束该操作。待确认写操作数量有上限。该机制不等于重启后的持久化事务日志；重连、关闭程序或改变操作参数后，应先到原服务器核对不确定的写入结果，不能无条件重新执行。
