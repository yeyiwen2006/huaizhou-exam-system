# PR #51 审查与修正记录

A 按用户授权独立审查 D04 精确计分模块，并将分支同步到包含 PR #50 的最新 main。#27 继续跟踪剩余接线及验收。

## 问题与修正

| 级别 | 问题与影响 | 修正 |
| --- | --- | --- |
| P1 | 选错分支枚举漏掉全部正确选项加额外错误项，会放过可达的除零规则 | 多项和不定项枚举 k 从 0 到正确选项总数，包含终点；按题型限定单项题选错时 k 为 0 |
| P1 | 重复选项 A、A 可在答案 A、B 时取得满分；未知选项和无效类型也可能返回成绩 | 判定及计分前检查作答结构、选项集合、题型和不作答权限，失败不返回分数 |
| P1 | 缺少答案记录被补成空选，但 A05 未保证冻结答卷覆盖全部题目 | 要求冻结记录与规则一一对应；未作答必须显式 Empty，缺失和多余题目都停止计分 |
| P1 | 重复题目可重复累计，重复参考答案会改变分支与选对数量 | 校验规则非空、全卷题号及题目标识唯一、选项和参考答案无重复、答案数量符合题型 |

原实现上复现 6 项失败。修正后新增题型和输入边界回归，同时保留原有精确小数、逐科归零和非法表达式检查。QuestionRule 增加 Type、AllowAbstain 以接收题组信息，新增 score.ruleInvalid 稳定规则码，样例文档同步说明。

dotnet restore Huaizhou.ExamSystem.sln --locked-mode
dotnet build Huaizhou.ExamSystem.sln --no-restore -c Release
dotnet test Huaizhou.ExamSystem.sln --no-build -c Release --filter "Category!=Postgres"

依赖还原成功，Release 构建 0 警告、0 错误。完整非 PostgreSQL 检查 1065 项通过，分别为领域及基础设施单元 820、学生端 89、管理端 76、学生身份 25、集成 33、负载工具 22。随后移除重复校验代码，再次构建仍为零警告、零错误，计分相关 36 项定向回归通过。
