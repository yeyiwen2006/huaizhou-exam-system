# PR #50 审查与修正记录

审查对象为 D03 学生包组包与加密部分，由 A 按本次用户授权独立审查、修正和验收。Issue #26 继续跟踪未完成的定位及接线工作。

## 发现及修正

| 级别 | 问题与影响 | 修正 |
| --- | --- | --- |
| P1 | 把 resourceRoots 当成逐文件允许清单，改名后的答案、64 KiB 后的字段及编译源文件可能随包分发 | 默认仅包含生成元数据及逐题 PDF；附加显示资源逐文件显式选择，核对类型、文件头和完整内容，记录排除原因 |
| P1 | 只反序列化清单，漏掉完整语义校验，../ 资源根可越界；没有阻止重解析点 | 复用 D01 完整校验与 PathBoundary，覆盖输入、逐文件读取和输出 |
| P1 | 加密前先把完整明文写入学生目录，与内存加密承诺不符 | 从内存快照直接生成加密 ZIP；明文目录仅用于调用方显式选择的服务器预览模式 |
| P1 | 固定 .partial 文件名、覆盖旧密文，密码学异常和取消后残留文件可能影响重试 | 独立临时文件，失败清理，最终路径禁止覆盖，成功前刷新文件 |
| P1 | 按平铺目录拼接 PDF，无法接收 D02 的 compile-* 独立目录 | 按 questionId 接收成功编译结果，并验证完整性、文件名及边界 |

原实现上的回归复现得到 7 项失败。修正后 Release 构建零警告、零错误，完整本地非 PostgreSQL 检查 1029 项通过，包含真实 TeX 编译与学生解码器往返。具体命令、数量和限制见 [实施状态](../d03-implementation-status.md)。

审查还核对了 AES-GCM 复用、节点信封、产物不可覆盖、输入材料不变、失败无虚假成功及异常信息不带材料内容。公共契约没有新增坐标结构，没有新增依赖或迁移。

## 验收边界

本次仅接受该 PR 已交付的组包与加密模块。PDF 正文及图片语义、选项定位、版本存储和客户端实际接线仍需继续完成。没有执行真实试卷、300 台设备或 T01/T02 整体验收。

远端 CI 必须覆盖修正后的最新提交且 Windows 与 PostgreSQL 两项通过，才可合并。最终结果记录在 PR #50 的审查意见及合并状态中。
