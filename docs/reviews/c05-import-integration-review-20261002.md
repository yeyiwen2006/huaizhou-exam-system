审查中还实测发现：在 Windows 上不必要地改变 CLI 全局输出编码，会影响既有进程调用方。因此最终保留现有 CLI 标准流行为，新进程测试沿用既有读取方式，而非修改旧接口来迁就新测试。

## 与当前考务接口的兼容性

保留 `GET /api/v1/exams`、`GET /api/v1/exams/{examId}`、`GET /api/v1/versioning/exams/{examId}`、`GET /api/v1/publications/recipients` 及 `POST /api/v1/exams/{examId}/publications/upload`。

上传仍为现有 `metadata` 与 `package` multipart 契约，不新增操作者字段、服务器目录、证书选择或发布版本输入框。操作者取既有登录身份；版本取服务器；正式成功还须匹配考试、资源、试卷版本、计分版本及对应规则标识。没有数据库迁移、私钥格式变更或新第三方依赖。

学生端继续消费 D03 的 v2 学生清单、逐题 PDF 与选项定位产物。合成端到端测试解密服务器保存的包，再调用既有学生读取器，并检查没有源 TeX、独立答案 JSON、计分规则或测试私有说明文件混入学生包。此允许清单检查不能替代对题目 PDF 正文本身的人工内容审查。

## CLI 用法及恢复

```text
exam-cli import preview 本地材料目录或ZIP --exam 考试名称 --output 新预览目录 --server https://服务器地址/
exam-cli import publish 预览目录 --confirm --server https://服务器地址/
```

使用当前 CLI 登录会话或既有凭据环境约定。预览操作不写服务器；输出目录必须是新目录。该目录包含敏感源材料、参考答案及 PDF，在 Windows 限制为当前账户和 SYSTEM，在其他受支持平台限制为当前用户。

检查失败不发布。确认后出现网络中断、超时或不能确认的响应，保留原预览目录，使用**同一目录**重试；已保存的发布请求、密文及其指纹不可被替换。同一预览通过独占锁阻止两个 CLI 进程同时发布。不要删除原记录后重新生成另一份发布请求来掩盖不确定结果。

考务 GUI 同样只认可当前预览和原请求回执；本次 GUI 的预览恢复范围为当前会话，不把 CLI 跨进程恢复测试当作 GUI 重启恢复验收。

## 可复现验证

所有材料、证书、账户、名称和题目均为合成数据。PostgreSQL 使用 `eng/testing/local_postgres.py` 创建、停止和清理独立回环 PostgreSQL 18 集群，不使用生产服务或数据库。环境包括 Windows、.NET SDK 10.0.401、TeX Live 2025/XeLaTeX。

```text
dotnet restore Huaizhou.ExamSystem.sln --locked-mode
dotnet build Huaizhou.ExamSystem.sln --no-restore --configuration Release
python eng/testing/run_checks.py --profile core --profile wpf --profile postgres --profile latex --profile import-e2e --postgres-bin "C:\Program Files\PostgreSQL\18\bin" --output .artifacts/c05-final
dotnet test tests/Unit/Exam.StudentUnitTests/Exam.StudentUnitTests.csproj --no-build --no-restore -c Release --filter Category=Latex
```

`import-e2e` 是显式要求 PostgreSQL 与 XeLaTeX 同时可用的交叉分类；普通 `postgres` 和 `latex` 分类排除它，避免 CI 将缺少另一依赖误报为覆盖完成。最终合并以整合 PR 当前提交的分类结果及 CI 为准，不复用两个候选 PR 的旧绿灯。

重点覆盖：29 项共享导入安全用例、13 项考务导入流程用例、现有整体发布回滚/并发用例、真实 CLI 的 ZIP→XeLaTeX→预览→确认→上传→跨进程原请求重放，以及学生端真实题包读取。另单独运行 `UiScreenshotTests`，在正常及最小窗口、100%/125%/150% 尺度输出合成页面截图，不把未设置截图开关时的空返回当作截图证据。
