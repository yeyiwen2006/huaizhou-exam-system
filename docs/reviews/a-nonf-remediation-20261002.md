## 第一批界面修复

**考试设置不再保留可写的上一场考试。** 切换开始就清除旧身份和旧编辑器，读取成功且身份一致才重新允许保存。每次异步返回均核对上下文；读取失败、连接更换、错误考试响应不能让旧设置恢复。保存过程中换考试或新建考试，不再继续执行旧请求的后续写入。结构已保存但时间请求失败时明确提示部分完成并要求重新读取，不再泛称全部成功。

**开考后名称、科目、题组只读。** 表格与命令采用同一权限条件，普通命令的执行方法也再次检查 `CanExecute`，不是只把按钮变灰。时间修改仍可按既有业务规则执行；没有时间变化时不会把不可保存的结构草稿当作成功。内部科目与题组编号不再出现在普通编辑列。

**名册从服务器读取并保存。** 手工新增、Excel 确认导入、身份更正和删除使用同一考试下的服务器版本。完全重复跳过，逐行冲突阻止整批写入，服务器未确认前不乐观地往名单里添加记录。网络中断保留同一操作以便幂等重试，版本冲突则要求显式刷新。切考试、切服务器、退出账号、迟到读取或写入回执均不会把旧名册放回当前页。已准备入场或参试的身份禁止删除、更换。

**试场和设备页面使用真实权威接口。** 新建、改名和删除保存到服务器；空组判断包含服务器上的全部关联设备，不取决于本页搜索结果。批准激活可选择已读取的真实试场，未指定归入未分组。设备按公开学生端编号、考生信息和试场查询，完整处理分页。单个或勾选多台设备转组时携带各自版本，成功后重新读取结果；转组历史显示前后试场、时间、操作账号和原因。后台刷新不会覆盖正在输入但尚未提交的试场名称。

学生端和考务端显示相同的短申请识别码，用于监考人员核对待审批申请；悬停可看完整申请编号。它是非秘密定位信息，不替代设备凭据或服务器鉴权。初次批准后未取得通信状态时明确显示尚未通信，不假装设备在线。

**考务截图测试已经改为实际登录并显示业务页面。** 测试通过进程内合成 HTTP 传输完成真实账号登录与考试读取，不修改生产鉴权，也不通过强行改可见性伪装已登录。截图前检查选中页确实可见、主区域未被登录页覆盖，拒绝不同页像素相同的结果，绑定错误使测试失败。42 张截图覆盖七页、两种窗口尺寸和三种渲染比例；渲染倍率不等同于真实 Windows DPI 验收。

第一批最新检查：Release 构建 0 警告、0 错误；考务端 243 项、学生端 388 项通过，均无失败或跳过；独立进程的考务截图用例通过。原来被截图数量掩盖的登录页重复问题不再会静默通过。所有图片和运行日志仅留在本机 `artifacts`，不提交仓库。
