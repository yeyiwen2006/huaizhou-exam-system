# 两个目录的代码同步

单机调试入口已退役。实际运行请按[服务器部署](../deploy/server/README.md)安装业务服务和管理服务，再从另一台 Windows 电脑运行考务端。旧的 `.artifacts/local-debug` 数据保持原样，代码同步不会处理其中的数据库、证书或日志。

## 手动同步代码

在任意一边双击根目录的 `sync-code.cmd`，默认同步同级的 `exam-system` 与 `exam-system-test`。在 PowerShell 中执行下面的命令，可以先查看待同步文件。

```powershell
python -X utf8 eng/development/sync_code.py --check
python -X utf8 eng/development/sync_code.py
```

同步范围包含已跟踪的项目文件，以及公共项目目录中新建的源代码、脚本和说明。新建的普通 JSON、PDF、表格、数据库、证书或日志不会因放入源码目录而自动加入同步。任意层级的 `机考单题文件`、`机考答案文件`、`.artifacts`、`artifacts`、`bin`、`obj`、私有材料目录，以及本地配置始终排除，即使误加入 Git 跟踪也不参与文件夹同步。两组试题目录还加入了 `.gitignore`，普通 `git add .` 不会收录它们。真实试题及答案应保存在这些私有目录中；放入公共源码或说明文件的内容会随该文件同步。

同步按上一次同步时的文件内容识别改动。一边修改、另一边未修改时更新另一边；两边改动后内容相同则接受；两边把同一文件改成不同内容时，整次同步停止并列出冲突。代码删除也参与同步；另一边仍是原版本时，删除会传播并先备份原文件，另一边已经修改则报告冲突。Windows 长路径和中文文件名可正常处理。

同步记录及被替换文件的备份位于测试目录的 `.artifacts/folder-sync`。保留这个目录才能继续识别两边各自的改动。遇到冲突时，先比较并合并两边内容，再执行同步。首次同步根据两边共同的已提交文件内容识别已有改动，没有共同基准的不同文件会保留并报告冲突。

两边的 `.git`、分支、提交、远端设置和构建产物各自保留。同步入口不会执行提交、推送或上传。程序改动会同步到原开发目录，运行产生的测试数据继续留在测试副本。正常运行时数据不会跟随同步进入原开发目录或远端；手动强制加入忽略文件、另行整目录上传或另改同步规则属于入口之外的操作。

## 通用源码与本地联调差异

正式目录和 GitHub 只保存正式运行所需的通用源码、模板和说明。tests/、eng/testing/、eng/manual-test/、本机联调/、测试截图，以及手工联调传输和配置适配器只保留在测试目录。联调信息.txt、真实连接配置、设备信息、试题和答案不会同步或上传。同步脚本不负责 Git 提交、推送，也不能自行判断任意一段代码是否只用于联调。

同一个通用文件中必须保留的少量联调差异，在测试目录的 .artifacts/folder-sync/test-overlays.json 登记。每一项包含已经人工合并核对的 public（正式内容）与 testing（本地联调内容）片段。脚本先将测试文件映射成正式内容，再按文件内容做双向比较；写回测试目录时恢复相应联调片段。片段不存在、重复、相互覆盖或两边出现未合并改动时仍报告冲突，不会猜测替换。

本次登记的差异包括联调配置读取、回环传输、登录预填和测试客户端配置引用。通用 global.json 均保持 SDK 10.0.402；本机缺少相应 SDK/运行时时，验证使用测试目录 .artifacts/ha-validation/dotnet-10.0.402 中的独立官方 SDK，不修改系统安装或降低正式依赖版本。没有登记的正式功能改动必须完整同步，不能放入联调覆盖片段隐藏。

记录格式为 {"version":1,"files":{"相对路径":[{"public":"正式片段","testing":"测试片段"}]}}。它只在本地同步记录目录保存；新增或修改规则前须比较实际差异。同步备份与原记录继续保留，不能为消除冲突而清空 .artifacts/folder-sync。同步成功后单独核对 Git 暂存文件范围，再提交通用源码与说明。

正式根解决方案 Huaizhou.ExamSystem.sln 仅包含通用程序项目，可在不具备 tests 的正式目录和 GitHub 构建。完整本地测试解决方案为测试目录 tests/Huaizhou.ExamSystem.Tests.sln；各测试项目也可单独执行。测试专用计划、覆盖清单、截图与测试工具仅在测试目录保存。GitHub 流程只构建正式源码；本地故障演练结果不能由远端构建状态替代。
