# ADR 0002 独立服务器管理与身份边界

状态为已采用，2026-10-17 补充方案 A 的独立故障接管入口；正常状态继续使用跨设备 HTTPS 管理与考务登录会话联动。

## 管理宿主独立于考试业务

管理功能由独立 `Exam.Management` 进程提供，监听部署配置指定的 HTTPS 地址，允许考务端从不同设备访问。未配置监听地址时使用回环地址。业务进程停止时，正式管理 API 和 CLI 仍提供状态、限定日志、状态检测、启停及备份恢复；考务 GUI 正常复用业务登录；业务不可用时从登录页“主服务器故障，直接进入服务器管理”独立登录目标管理宿主。日常业务启停仍由 API/CLI 提供；“接管为主服务器”会在完成提升后自动启动业务并核对就绪。

管理操作使用 `Exam.Contracts` 与统一 JSON 规则。GUI 的服务管理页和 CLI 的 `management` 命令复用 `LocalManagementClient`；服务控制目标、工具路径、目录和节点由受保护部署配置绑定，请求不能任意指定命令、主机或服务。

## 账号与会话

正常考务 GUI 使用当前业务令牌安全换取目标管理会话，服务端核对当前账号身份和权限，不再次收集用户名和口令。故障入口使用原考务账号和口令调用独立管理登录，备库可达时读取复制来的启用账号。退出考务、切换账号或业务会话失效时清除旧管理权限。

GUI 故障入口与 CLI 使用 `POST /management/v1/login`，使用考务用户名和口令获取管理会话。数据库可用时验证启用状态并刷新本机加密缓存；Windows 数据库暂不可用时，用缓存中的已启用账号口令哈希和管理员标记核对。Linux 不使用 Windows 离线缓存，管理登录需要数据库可达。缓存不含明文口令。

独立登录的离线缓存无法获知停库前尚未同步到该机器的账号变更，恢复连接后重新核对。GUI 的业务令牌交换不使用这份缓存代替业务会话认证。不得使用匿名管理、共享默认口令、硬编码令牌或绕过服务端认证的身份字段。

管理会话仅在目标管理进程有效，不能替代业务会话或学生设备凭据。业务接口每次按当前数据库状态验证权限。退出后旧会话失效，敏感数据与日志不得向未认证调用方返回。

## 变更、审计与恢复

变更请求绑定原请求标识、已认证操作者、逻辑服务器、本机节点、类型和内容摘要。同号不同内容拒绝，原请求查询和重试重新核对身份，不产生第二个不确定操作。长任务在执行前持久记录，查询返回阶段、结果及是否需要核对；取消不等于副作用已经回滚。

本机配置使用预期版本防止覆盖他人修改。未经核实的数据库角色和代次可返回未知，不编造业务就绪。管理登录成功不代表考试业务可以写入。

备份、隔离恢复、状态检测、启停与日志见[服务管理](../service-management.md)。GUI不展示代次，合并显示服务器状态，查询默认使用最近操作并允许输入历史编号；页面不再单列待核对请求，处理情况由操作结果展示。原请求重放、恢复续行和业务启停保留在正式管理API和CLI。接管、自动单节点持久确认、重建与恢复复制保护见[主备管理契约](../high-availability-management.md)，底层继续执行旧主隔离、数据副本、资源、密钥、身份和代次检查。

## 验证边界

分别验证业务令牌交换、业务故障时的独立管理登录、退出与换账号后的权限清理、未认证请求拒绝、CLI在业务停止时查询和启停、重复请求、重启查询、目录与服务绑定、权限错误以及危险操作确认。真实服务账户、部署证书、双机网络和断电恢复按[验收标准](../acceptance-criteria.md)执行，当前尚未完成真实服务器部署验收。
