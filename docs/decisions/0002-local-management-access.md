# ADR 0002 独立服务器管理与身份边界

状态为已采用，2026-10-13 更新为支持跨设备 HTTPS 管理。

## 管理宿主独立于考试业务

业务进程停止、恢复中或数据库暂不可读时，考务人员仍需查询状态、查看限定日志、执行自检、启停服务及提交备份恢复操作。因此管理功能由独立 `Exam.Management` 进程提供，监听部署配置指定的 HTTPS 地址，允许考务端从不同设备访问；未配置监听地址时使用回环地址，不放入学生业务 API。

管理操作使用 `Exam.Contracts` 与统一 JSON 规则。GUI 的服务管理页和 CLI 的 `management` 命令复用 `LocalManagementClient`；服务控制目标、工具路径、目录和节点由受保护部署配置绑定，请求不能任意指定命令、主机或服务。

## 账号与会话

`POST /management/v1/login` 使用考务用户名和口令获取本进程管理会话。数据库可用时验证启用状态并刷新本机加密缓存；Windows 数据库暂不可用时，用缓存中的已启用账号口令哈希和管理员标记核对。Linux 不使用 Windows 离线缓存，管理登录需要数据库可达。未取得缓存的账号不会凭空获得离线权限，缓存不含明文口令。

离线缓存有状态滞后边界：停库前尚未同步到该机器的账号变更无法离线获知，恢复连接后重新核对。不得使用匿名管理、共享默认口令、硬编码令牌或绕过服务端认证的身份字段。

管理会话仅在目标管理进程有效，不能替代业务会话或学生设备凭据。业务接口每次按当前数据库状态验证权限。退出后旧会话失效，敏感数据与日志不得向未认证调用方返回。

## 变更、审计与恢复

变更请求绑定原请求标识、已认证操作者、逻辑服务器、本机节点、类型和内容摘要。同号不同内容拒绝，原请求查询和重试重新核对身份，不产生第二个不确定操作。长任务在执行前持久记录，查询返回阶段、结果及是否需要核对；取消不等于副作用已经回滚。

本机配置使用预期版本防止覆盖他人修改。未经核实的数据库角色和代次可返回未知，不编造业务就绪。管理登录成功不代表考试业务可以写入。

备份、隔离恢复、自检、启停与日志见[服务管理](../service-management.md)。接管、应急、重建与恢复同步保护见[主备管理契约](../high-availability-management.md)。这些操作继续执行旧主隔离、数据副本、资源、密钥、身份和代次检查；服务器管理权限不授权跳过保护。

## 验证边界

分别验证普通账户、独立管理身份、未登录拒绝、业务停止时查询和启停、重复请求、重启查询、目录与服务绑定、权限错误以及危险操作确认。真实 SCM 账户、部署证书、双机网络和断电恢复按[验收标准](../acceptance-criteria.md)执行，模块测试不代替现场结果。
