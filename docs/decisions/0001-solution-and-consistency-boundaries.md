# ADR 0001：解决方案与一致性边界

状态：已接受，M0

系统采用 .NET 10、WPF、ASP.NET Core、SignalR 和 PostgreSQL 18。跨端字段集中在 `Exam.Contracts`，领域状态机不访问外部资源，业务入口共享 `Exam.Application`。正式服务器状态由 PostgreSQL 事务和唯一约束保护；本地锁只用于测试参考实现。

选择这一边界是为了让 GUI、CLI 和 API 使用相同规则，也使编号、授权、最终答卷、可靠事件和版本发布可以在数据库层建立原子约束。代价是基础设施接入前不能把内存实现视为生产完成，数据库迁移和契约变化也必须同步审查。
