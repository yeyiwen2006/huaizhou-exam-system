## 本轮修正

原 PR 从旧 Mock 工作副本整理而来，包含对当前 A、B01、B02 代码和测试的回退。本轮保留主分支已有的 HTTPS 身份验证、真实题包解锁、SignalR 指令处理、DPAPI 保护及服务器实现，移除重新带入的生产 Mock 和合成试题入口，仅整合 B04 及必要的启动修正。公共服务端契约没有降级或改写。

| 项目 | 当前实现 |
| --- | --- |
| 本地事务 | Microsoft.Data.Sqlite 10.0.12，WAL 与 FULL 同步，专用工作线程串行处理磁盘操作。一次编辑涉及的答案、私人标记、当前题、版本和待发送快照同事务保存。 |
| 身份隔离 | 以可信逻辑 serverId、examId、该考试的 candidateId 为键，不用服务器地址或姓名作为键；保存设备、参试记录及进入/授权版本。 |
| 版本及并发 | 答案、标记、切题通过同一会话门控串行操作。每次成功编辑递增版本；存储层拒绝版本回退、授权不符和固定后的改写。 |
| 写入失败 | 最后可靠版本不变，同时保留内存中待保存的编辑；禁止新增修改。重试先保存原待保存内容，再决定是否可以恢复作答，不把未落盘内容显示成已保存。 |
| 私人标记 | 与答案一起可靠保存，按身份隔离；不会进入待发送进度或最终提交载荷。 |
| 固定提交 | 首次固定立即停止编辑，深拷贝答案并保留唯一 submissionId、稳定 requestId 和原授权。落盘失败也保持原待固定记录，只能重试它；已成功固定后重复请求沿用原记录。 |
| 恢复保护 | 读取或校验失败明确阻止作答并保留文件，不删除旧数据或重新建立空答卷。旧授权、其他设备、重复启动串号不能重开答案会话。 |
| 数据库保护 | 检查数据库完整性、架构及初始化标识；缺失既有数据库、未知旧架构或不完整关联状态时拒绝静默初始化。初始化异常会明确结束请求，不让工作队列永久等待。 |
| 真实运行时接入 | 答案会话属于 StudentExamRuntime，跨页面保留。先只读检查固定提交；正常答题恢复必须在本轮 B02 服务器核准并成功解锁之后进行。END、授权失效和关闭会话会阻止继续修改。 |
| 页面反馈 | 等待页和考试页显示本地恢复/可靠保存/故障状态，提供本地保存重试。保留 B03/B05 未完成的明确提示，不启用写死题目和虚构交卷成功。 |
| Windows 启动 | 修正学生端清单中无效的 DPI 元素，并用 Windows 激活上下文解析验证；普通用户运行权限保持不变。AppDataDirectory 在最新主分支中已位于 Services 之前，本轮不重复宣称修复该项。 |

待发送进度和固定答卷记录面向 B05 使用，具有稳定请求标识和完整授权字段。答案类型仍遵守 shared contracts 中 empty、selected、abstain 三态，不修改 AnswerValue 的全局相等性语义。凭据和题包恢复继续使用 B01/B02 已有的当前用户 DPAPI 存储，不复制到 SQLite 或写入日志。

- **B03 × B04 真实交互联调**：B03 尚未接入完整逐题模型和选项交互，因此目前不生成示例题号，也不把空字典当作完整答卷。接入后须验证所有题目操作使用同一 AnswerSession，重启恢复题号、答案和私人标记，切换考生不串号。
- **B05 × A05 上传与回执**：消费已保存的进度/固定提交记录，补齐实际网络发送、原请求重试、查询及保存服务器回执。只有取得可信持久化回执才显示成功；已有固定记录时优先恢复原任务，不能重新参试或生成新答卷。
- **完整 END 交卷链路**：当前 B03/B05 尚未就绪的页面只停止答题并保留原记录，不伪造完整快照。接通真实全量答案后，提前交卷和 END 都必须调用同一个固定提交入口，再重试原快照；不能因本机时钟到点丢弃答案。
- **换设备/跨机恢复**：仅保存本地授权字段不代表已完成换机恢复。仍需面向当前授权设备的服务器持久进度查询及 B08 重连联调；不能将旧设备离线答案自动合并。
- **现场验收**：S03/S07 的真实答题后强制结束进程与重启恢复、S18 的真实不可写/磁盘写满后继续保存，及独立的 S19 断电检查尚需在完整界面链路和隔离环境完成。本轮不据此宣称现场验收通过。
